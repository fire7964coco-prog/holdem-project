## 1. ★이 시리즈의 성격 — 경험담을 넣지 않는다

**2026-08-08 사장님 결정.** CLAUDE.md §8은 "모든 포스트에 실제 경험담 필수"를 요구하지만
**이 시리즈는 예외다.**

> 사장님: *"이건 일반적인 포스팅이 아니라 GTO 솔버의 13가지 상황을 하나씩 설명해주는
> 포스팅이라서 굳이 개인 경험이 안 들어가도 되지 않을까. 오히려 구글 AI 답변을 하기 어려운
> 고급 계산이기 때문에 오히려 오피셜하게 객관적 정보 제공은 어떨까."*

**왜 예외가 정당한가**: §8의 취지는 «AI가 지어낸 일반론 글»을 막는 것이다. 이 13편은 성격이
정반대다 — **우리가 만든 솔버로 직접 계산한 1차 데이터**이고, 구글 AI 답변이 만들어낼 수 없는
구체적 수치가 본체다. E-E-A-T의 Experience는 "직접 계산해서 얻었다"로 이미 충족된다.

**대신 «재현 가능성»이 출처를 대신한다. 이 셋은 매 편 필수다:**

1. **계산 조건 표** — 프리플랍 액션 · 레인지 · 플랍 · 팟/스택 · 벳 사이즈 · **레이크 미고려**
2. **0.1bb 단위 안내** — 솔버 화면의 「팟 55」는 5.5bb, 「EV 20.9」는 2.09bb
3. **「직접 확인해보기」 절** — 교육 예제 이름을 정확히 적어 원클릭 재현시킨다

## 2. 글 구조 (1편에서 확립)

```
히어로 이미지(솔버 화면)
도입 — 독자의 질문/오해로 시작 ("탑 페어인데 먼저 벳하는 게 맞을까요?")
:::stripe  스팟 / 플랍 / 팟·스택 / 결론 4줄
> **바로 답**   ← 2~4줄 자기완결 단락
## 이 수치는 어떤 조건에서 나왔나요?   ← 계산 조건 표 + 0.1bb 안내
## <핵심 수치>가 정확히 얼마인가요?    ← 액션 빈도 표 + 두 번째 이미지(액션 대비)
## <독자의 반문>이 맞나요?             ← "탑 페어인데도 체크가 맞나요?"
## 왜 <그 결과>가 나오나요?            ← 레인지 구성 표
## 에퀴티/EQR 해석
## 그럼 상대(IP)는 어떻게 쳐야 하나요?
## 실전에서 무엇을 바꾸면 되나요?      ← 불릿 3개
## 직접 확인해보기                     ← 교육 예제 CTA
**Q. …**  (빈 줄)  A. …   × 4문항
```

- **질문형 H2 70% 이상**(§14-A). 1편은 8개 중 7개가 질문형이다.
- 어투는 **존댓말 + 평서체**(본체 톤). 반말 금지 — 참고했던 포커고수 글은 커뮤니티 반말이지만
  본체는 「습니다/입니다」다(945/913회 대 「해요」 41회).
- 포커고수 글에서 **가져온 것은 «전개»뿐**이다: ① 독자의 오해를 먼저 꺼내 반박 ② 같은 스팟에서
  조건을 바꿔 대비 ③ 개념을 그림으로 증명.

산출물은 `.solver-captures/`(gitignore)에 쌓이고, webp만 `public/images/`로 들어간다.

| 파일 | 내용 | 용도 |
|---|---|---|
| `gto-<key>-oop.webp` | 첫 액션 플레이어의 **전략 화면** — 보드·팟·액션 빈도·매트릭스·핸드/드로우 분류가 한 장에 | **히어로** |
| `gto-<key>-ranges.webp` | 두 플레이어의 **등급별 레인지 구성 비교**(자체 제작, 1200×675) | 본문 |
| `.solver-captures/data.json` | 액션 빈도 · 핸드/드로우 분류 · EQ/EV/EQR **양쪽 전부** | 본문 수치의 원천 |

### 3-2. 🔴 예전 `_ip` 캡처 26장은 쓰면 안 된다

핸드오프에는 "26장 전부 OOP 화면이고 차이는 하이라이트된 액션뿐(픽셀 차이 0.2~0.9%)"이라고
적혀 있었는데 **틀렸다.** 실제로 매트릭스 영역을 픽셀 비교하면

- 같은 스팟의 `-oop` ↔ `-ip` : **54.8% 차이** (완전히 다른 그림)
- **보드가 다른 스팟끼리의 `-ip` ↔ `-ip` : 0.12~0.21% 차이** ← 여기가 0.x%였던 것

즉 `-ip`는 **보드와 무관한 IP의 «프리플랍 레인지» 화면**이다. AA·KK·AK가 들어 있고 K4s·Q5s는 빠져 있다.
「결과 바로 보기」는 플랍 첫 액션 노드만 계산해 두는데 **첫 액션은 OOP 차례**라, IP 쪽에는 전략이 없고
레인지와 EQ/EV/EQR만 있다. 그래서 `-ip` 화면에는 보드별 정보가 **0**이다.

①편이 이걸 "같은 화면에서 벳으로 가는 핸드만 노란색으로 표시한 것"이라고 설명하고 발행돼 있었다.
BB 레인지에 없는 AA·KK가 칠해진 그림이므로 **§13 사실오류**다. 13장 전부 삭제했다.

> **교훈**: 파일명을 믿지 마라. 그리고 **"차이가 0.x%"라는 비교 결과를 받으면 «무엇과 무엇을 비교했는지»를 먼저 확인하라.**
> 이번 오진은 비교 대상을 잘못 짝지은 것이었다.

### 3-3. 매 편 지킬 것

- **이미지 2장을 Read로 열어 육안 확인**한 뒤 캡션을 쓴다. 좌상단 패널의 플레이어(OOP/IP)와 액션 빈도가
  본문 수치와 맞는지 본다.
- 캡처는 `deviceScaleFactor: 2`로 뽑는다. **`document.documentElement.style.zoom`을 쓰면 안 된다** —
  앱이 `window.innerWidth`로 매트릭스 셀 폰트를 정해서, 줌을 걸면 글자가 셀보다 커져 서로 겹친다.
- **가상 스크롤 표는 끝까지 내려서 세라.** ⑤편에서 화면에 보이는 34행만 보고 「너트 플러시 7콤보·평균 체크 68.5%」로
  적었는데, 전체 469행을 훑으니 **8콤보·69.9%**였다(A♠3♠이 아래 있었다). 보이는 것이 전부가 아니다.

### §4-B-3. 재솔브 수치 — ⑦ 체크레이즈 (2026-08-20 · **정본과 섞지 마라**)

⑦편(KO·EN 양쪽)은 §4-B 교육 예제 **밖의 수치**를 쓴다. 위 4번 이유로 체크레이즈가 예제에 없어서다.
**출처가 다르므로 §4-B에 합치지 않는다.** 인용할 때는 반드시 「자체 재솔브」라고 밝혀야 한다.

| 항목 | 값 |
|---|---|
| 트리 | flop bet **33** · raise **60** · pot **55** · stack **975** (교육 예제와 동일) |
| 설정 | **190 iterations · exploitability 0.16 = 팟의 0.29%** · 16-bit integer · 12 threads |
| 재솔브 루트 | Check **98.0%**(477.5) · Bet 1.8bb **2.0%**(9.5) · All 487.0 |
| BB 체크 후 BTN | Bet 1.8bb **63.0%**(316.5) · Check **37.0%**(186.5) · All 503.0 |
| 그 벳에 대한 BB | Raise 7.3bb **14.9%**(69.7) · Call **65.6%**(314.6) · Fold **19.5%**(93.2) · All 477.5 |

🔴 **7.3bb를 «팟 사이즈 레이즈»라고 쓰지 마라** (2026-08-20 적대검수에서 두 렌즈가 독립으로 잡았다).
   팟 레이즈는 «콜한 뒤의 팟»을 레이즈한다 — 5.5 + 1.8 + 1.8 = 9.1 → raise-to **10.9bb**.
   7.3bb의 실체는 (7.3 − 1.8) ÷ 9.1 = **60% 팟 레이즈**이고 트리 설정 `raise 60`과 일치한다.
   「7.3 = 5.5 + 1.8」은 참이지만 거기서 «팟 사이즈»를 끌어내면 거짓이다.
🔴 **패널 백분율과 콤보 수가 이 노드에서 어긋난다** — 69.7 ÷ 477.5 = **14.6%**이지 14.9%가 아니다
   (BTN 노드도 316.5 ÷ 503 = 62.9% 대 표시 63.0%). **표시값을 쓰되 이 사실을 본문에 밝혔다.**

🔴 **재솔브 루트의 리드는 2.0%로 교육 예제의 3.2%와 다르다.** 등급·드로우·EQ·EV·EQR은 소수점까지 같다.
   이 보드의 리드는 EV 차가 0에 가까운 «거의 무차별» 액션이라 솔브마다 흔들린다.
   **두 값을 같은 표에 넣지 마라** — 문장은 다 참인데 결론이 거짓이 되는 자리다.
🪶 핸드별 표는 **487행 전수 캡처**(가상 스크롤 누적)로 얻었다. 레이즈 100% = 66·55·22(9콤보) +
   65s(2콤보) + 64s. 블러프는 98s·87s·J4s·Q4s·54s로 **전부 스트레이트 드로우**다.
