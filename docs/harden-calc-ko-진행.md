- ICM: Malmuth-Harville 재귀를 독립 계산으로 대조했다. 4인 버블 `60k/40k/30k/20k`, 상금 `500k/300k/200k`에서 `332,634/272,405/228,698/166,263원`, ICM `33.3/27.2/22.9/16.6%`, 차이 `-6.7/+0.6/+2.9/+3.3%p`를 실제 UI에서 확인했다. 3인 딜 `50/30/20`, 상금 `90/40/20만원`의 ICM `617,857/485,000/397,143원`도 독립 재계산과 일치했다.
- ICM 문구: 승리·무승부·패배 후 가치를 실제 확률로 가중하는 콜/폴드 비교, 원시 칩찹 열, `%p`, 미들스택 리스크 프리미엄·극숏 예외, 세이브 앤드 칩찹과 ICM 한계를 반영했다.

## 5. 헤드 요청

- SPR는 표시용 0.1 반올림값으로 존을 판정해 실제 3.95~3.99, 7.95~7.99, 14.95~14.99가 상위 존으로 넘어간다. `calculator-tool.tsx`와 KO가 같은 결함이므로 공용 판정·전 로케일 회차가 필요하다.
- Rule of 4·2 설명 바로 아래에 정확값을 함께 보여 주면 9아웃츠의 `36%`와 `35.0%`가 충돌처럼 보인다. 근사치·정확값의 역할을 전 로케일에서 더 분명히 분리할 필요가 있다.
- EN 정적 표의 `7 outs = set to full house/quads`는 두 스트리트 고정 7아웃츠의 27.8%와 맞지 않는다. 플랍 셋은 턴 미스 뒤 새 보드 랭크까지 페어링 아웃이 되어 리버 아웃츠가 10장으로 늘고 실제 두 장 확률은 약 33.4%다. KO는 예시를 비워 두었고 EN·다른 로케일의 같은 행은 공용 회차에서 바로잡아야 한다.
- EN FAQ의 콜/폴드 ICM 비교는 승리·패배 값을 단순 평균하라고 적혀 있다. 실제 승률(무승부 포함) 가중 기댓값으로 바꾸고, `dict.ts`의 설명 누락도 함께 보완해야 한다.
- EN을 포함한 공용 ICM 설명의 `+차이/−차이`와 버블 조언은 부호만으로 행동을 결정하는 듯한 과잉 일반화가 있다. 보통 미들스택의 리스크 프리미엄이 가장 크며 극단적 숏스택은 예외라는 조건을 전 로케일에서 검토해야 한다.
- ICM 입력은 상금 내림차순을 검증하지 않아 1등 상금이 2등보다 작은 구조도 계산한다. 공용 입력 검증이 필요하다.
- ICM 플레이어 아이콘의 메달은 성적 순위가 아니라 입력 순서에 붙어 오해를 부를 수 있다. 공용 UI 표식을 검토해야 한다.
- 동적 차이는 비율의 차이이므로 KO는 `%p`로 바로잡았다. EN·다른 로케일의 `%` 표기에도 같은 의미 정정이 필요한지 공용 회차에서 확인해야 한다.
- 위 항목은 이번 KO 단독 회차에서 EN·공용·다른 로케일로 확대하지 않았다.
