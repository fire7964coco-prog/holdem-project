## 3. 타이포그래피

- **소수점 = 쉼표**(77,9) · **% 앞 공백**(99,9 %) · 인용은 « »(내부 공백) — 앱 fr과 동일.
- 큰 수 구분: espace(8 100) — 단 랜딩·뱅크는 볼륨 표기를 벤더 원문(8,100)으로 두기도 한다. 본문 렌더 텍스트는 프랑스식.

## 4. 콘텐츠 지형 (누가 쓰나)

- **포럼이 깊이를 갖는다**: Club Poker(PioSolver 유저 스레드 — 파라미터·정밀도 논쟁 수준 높음) ·
  Poker Académie(GTO Wizard 평가 — nodelock·sizing 단순화 논쟁). 독자는 «단순화 전략»에 우호적
  («La sim basic est largement suffisante» — 6사이즈 트리 재현 불가론이 다수파).
- 매체(pokerlistings.fr 등)는 어필리에이트 리뷰 위주로 얇다 — 정확·심층이면 이긴다.
- Winamax가 무료 마스터클래스 등 콘텐츠 강자(Poker52 인터뷰) — 개념 교육 축은 경쟁 치열,
  «도구가 직접 돌아가는 페이지» 축은 비어 있음.
