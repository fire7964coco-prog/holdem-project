# DESIGN.md — 홀덤마스터 디자인 기준 (읽는 안내서)

> 🔴 **값의 정본은 `app/globals.css`다.** 이 파일은 «어떤 토큰이 무슨 역할이고 무엇을 하면 안 되는가»만 적는다.
> 색 값을 여기서 고치지 마라 — 두 곳에 적으면 갈라진다. 아래 hex는 HSL에서 «환산한 참고값»이다.
> 용도: `screen-review`·`solver-design`·큐 레인의 이미지 회차가 화면을 판정할 때 먼저 읽는 기준. (2026-09-11 신설 · lazyowen 「디자인 시키기 전에 깔아야 하는 5개」 STEP 2의 우리판)

## 1. 한 줄 정체성

**따뜻한 크림 라이트 테마 + 진한 포레스트 그린 글자 + 24K 골드 강조.** 커뮤니티 피드와 같은 톤. 다크 테마 없음(다크 «표면»만 있다 — 상단 바·팝오버·썸네일).

## 2. 토큰 역할표 (`app/globals.css` `:root`)

| 토큰 | 역할 | 참고 hex | 쓰는 자리 |
|---|---|---|---|
| `--background` 37 33% 93% | 페이지 바탕(크림) | ≈ #F3EEE6 | body · 라디얼 그라디언트 2겹 위 |
| `--foreground` 152 45% 8% | 본문 글자(포레스트 그린) | ≈ #0B1D15 | 모든 텍스트 기본 |
| `--card` 40 45% 97% | 카드·패널(밝은 크림) | ≈ #FBF8F3 | 글 본문 카드 · 사이드 카드 |
| `--primary` 43 65% 44% | **밝은 배경용 골드**(채도 낮춤) | ≈ #B99027 | h1~h6 · 링크 강조 · 포커스 링 · 선택 영역 |

| `--secondary` 36 22% 86% / `--muted` 36 20% 90% | 탄(tan) 보조면 · 무광 | ≈ #E2D8C9 / #EAE4DC | 배지 · 보조 버튼 · 구분 |
| `--muted-foreground` 30 22% 36% | 보조 텍스트 | ≈ #705B48 | 캡션 · 메타(읽는 시간·날짜) |
| `--border` 36 18% 80% | 보더 | ≈ #D6CBBD | 카드 테두리 · 표 선 |
| `--destructive` 0 72% 50% | 경고 | ≈ #DB2424 | 삭제·오류만 |
| `--radius-sm/md/lg/xl` | 0.375 / 0.625 / 0.875 / 1.125 rem | | 버튼 sm · 카드 lg · 히어로 xl |

🔴 **골드는 «둘»이다 — 통일하지 마라.** `--primary`(#B99027)는 크림 위에서 대비를 내려고 채도를 낮춘 값이고, `--gold-dark-rgb`(#D4AF37)는 다크 그린 위에서 대비를 내는 원색이다. 배경별로 갈린 쌍이지 부채가 아니다(globals.css 주석 · 2026-08-18).

## 3. 글꼴

- 본문·제목 전부 **Inter(영문·숫자) → Noto Sans KR(한글)** 한 계열. `next/font/google` 자체 호스팅 · `display: swap`.
- 세리프 없음(EB Garamond 제거 · 한글 혼용 굵기 불균일 때문). `font-serif` 토큰도 sans로 매핑돼 있다 — 제목에 세리프를 «다시» 넣지 마라(백로그 「제목 세리프(Lora)」는 LCP 측정과 같이 열 때만).
- 제목 = 700 · `tracking-tight` · 골드 · 옅은 텍스트섀도.

## 4. 지켜야 할 것 (게이트·규율이 있는 자리)

| 규칙 | 근거 |
|---|---|
| 텍스트 대비 WCAG AA ≥ 4.5:1 | globals.css 머리 주석 · 라이트하우스 a11y 100 |
| `:focus-visible` 골드 2px 링 — 지우지 마라 | 키보드 사용자 |
| `prefers-reduced-motion` 존중 — 무한 애니메이션 금지 | 메모리 perf(무한 애니 = LCP 착시) |

| 인포그래픽은 온브랜드(골드/그린/그레이 · 크림 배경) · 글자 든 것은 HTML+Playwright로 | §9-1 |
| 모바일 먼저 본다(390) — 신규×모바일×블로그상세가 약점 축 | 메모리 mobile-engagement-gap |
