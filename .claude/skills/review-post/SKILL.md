# review-post

## 첫 행동 — 프로토콜 본체를 읽는다

**`REVIEW-PROTOCOL.md`(레포 루트) 전체를 Read 하고 그대로 따른다.**
검수 절차의 본체는 그 파일 하나다. 이 스킬 파일에는 절차를 복사해 두지 않는다 —
두 곳에 적으면 반드시 갈라지고, 갈라진 쪽을 읽는 순간 오늘 고친 것이 내일 되살아난다.

```
Read: REVIEW-PROTOCOL.md
```

## 요약 (본체를 읽기 전 방향만)

| 층 | 무엇 | 누가 |
|---|---|---|
| 1층 | §13 검산 · 메타 · 링크 · 축어중복 · 표 교차대조 | **기계** `npm run audit:hard -- --slug=<slug>` |
| 2층 | 기계가 판정 못 한 카드 문단 | **사람** `--uncovered` |
| 3층 | D유형(전략적 유해 조언) · F유형(사실 오류) | **적대적 렌즈** (Agent, 렌즈를 다르게) |

**전제**: 같은 검수를 반복해도 검출률은 오르지 않는다. 읽어서 통과시킬 수 있는 검사는
그럴듯하고 틀린 글이 반드시 통과한다. 그래서 계산으로만 검증되는 것은 기계에 맡기고,
사람은 기계가 원리상 못 보는 곳에만 시간을 쓴다.

**게이트가 초록이어도 검수가 끝난 게 아니다** — 3층은 별도로 돌린다.
