# th 포커 용어·표기 브리프 (번역 착수 전 웹리서치 결과)

> 대상 = **태국어(th, ภาษาไทย)**. 태국 포커 글로시(ggpoker.com/th · thaipokerbeast.com · natural8.com/th · th.wikipedia · dummy.gameindy.com) 기준. 태국은 **영어 음차 우세 + 일부 고유 용어**. ★**직역 아님 — 현지 맥락 재구성**.

## ⚠️ 태국어 표기 특성 (중요)
- **태국어는 단어 사이 띄어쓰기가 없다**(공백은 절/문장 구분에만). 자연스러운 태국어로 붙여 쓸 것. 라틴 영어 용어(Texas Hold'em, all-in 등) 삽입 시 앞뒤 공백 자연스럽게.
- **숫자 = 아라비아 숫자(0-9)**. 태국 숫자(๐-๙) 쓰지 말 것(현대 디지털/게이밍 표준이 아라비아).

## 용어 (현지 관습)
- **족보 (태국어 음차+고유명, 첫 등장 시 영어 병기)**:
  - Royal Flush → **รอยัลฟลัช**
  - Straight Flush → **สเตรทฟลัช**
  - Four of a Kind → **โฟร์การ์ด** (또는 โฟร์ออฟอะไคนด์)
  - Full House → **ฟูลเฮาส์** (= 1 ตอง + 1 คู่)
  - Flush → **ฟลัช**
  - Straight → **สเตรท**
  - Three of a Kind / set → **ตอง** (ตอง = 고유 태국어 trips)
  - Two Pair → **สองคู่**
  - One Pair → **คู่** (또는 วันแพร์)
  - High Card → **ไพ่สูง** (또는 ไฮการ์ด)
  - ★홀덤 순서 = **ฟูลเฮาส์ > ฟลัช**(풀하우스>플러시 표준, 태국 소스도 동일 — 변형 없음).
- **액션(태국어+영어 음차)**: check → **เช็ค**, bet → **เดิมพัน / เบท**, call → **เรียก / คอล**, raise → **เพิ่มเดิมพัน / เรซ**, fold → **หมอบ / พับ / โฟลด์**, all-in → **ออลอิน**. 첫 등장 후 자연스러운 쪽.
- **블라인드**: Blinds → **บลายด์**, Small Blind → **สมอลบลายด์ (SB)**, Big Blind → **บิ๊กบลายด์ (BB)**. 영어 SB/BB 병기 가능.
- **스트리트/구조**: พรีฟลอป(preflop), ฟลอป(flop), เทิร์น(turn), ริเวอร์(river). รอบเดิมพัน(betting round), ไพ่ชุมชน(community cards), ไพ่ในมือ/ไพ่ปิด(hole cards).
- **핵심 명사**: card → **ไพ่**, hand(패) → **มือ / ไพ่ในมือ**, hand rankings → **ลำดับไพ่ / อันดับไพ่**, dealer → **ดีลเลอร์**, button → **ปุ่ม / บัตตอน (BTN)**, pot → **พอต / กองกลาง**, main pot → **พอตหลัก**, side pot → **ไซด์พอต / พอตข้าง**, kicker → **คิกเกอร์**, showdown → **โชว์ดาวน์ / เปิดไพ่**, suit → **ดอก**, stack → **สแตก / กองชิป**, chips → **ชิป**, Bluff → **บลัฟ**, ante → **แอนตี้**.
- **포지션 약어는 영어**(첫 등장 병기): UTG, CO(Cutoff), MP, HJ, SB, BB, BTN.

## 표기 (⚠️ **영어식 계열: en·zh·ar·ms와 동일 — 변환 없음**)
- **숫자 = 영어식 그대로**: 천단위 `,`(1,326·198,000 그대로), 소수점 `.`(2.5·2.7:1 그대로), % `35%`. **§13 값 표기 변환 불필요**(태국은 아라비아 숫자·영어식 구분자). 유럽식(1.326/2,5)으로 바꾸지 말 것.
- **카드 표기 라틴 유지**: `A♠`, `K♥`, `10♦`, 보드 그대로. 무늬 기호 ♠♥♦♣ 그대로.
- **화폐**: `$` 그대로(§13 보존 — ฿/บาท로 바꾸지 말 것).

## 문체
- **คุณ**체(정중·중립 2인칭, 태국 콘텐츠 표준) 또는 자연스러운 주어 생략. 태국 포커 커뮤니티(GGPoker th·ThaiPokerBeast)가 실제 쓰는 구어체(딱딱한 번역 티 금지). 태국어는 띄어쓰기 없이 자연스럽게.
- 태국 문자 성조부호·모음 표기 정확(สระ·วรรณยุกต์). 오타 = §13급 신뢰 리스크.

**근거 읽는 법:** 링크는 절 끝 URL 정의를 참조한다. « »는 검색 요약이 아닌 직접 열린 태국어 원문의 짧은 축어다. 태국어 페이지 안의 영어 표제·전문어도 실제 용례로 인정하되 영어 페이지로 이동한 결과는 제외했다. 인용은 낱말 사용만 확인한다. 해당 사이트의 계산·전략·상품 주장이나 합법성 판단을 채택하지 않는다. 운영사 페이지는 낱말 자료이며 홍보·이용 권유가 아니다. 대소문자·하이픈·접두사 생략·동사 명사화·짧은 목적어 생략은 메모에 밝힌 편집 정규화다. 산문 용례를 실제 버튼에서 확인했다고 보고하지 않으며, 한 사이트만으로 현지 사용 빈도를 단정하지 않는다.

**미확인 = 확정 번역 아님. 총 236행 중 미확인 81행(전부 미확인 75 + 부분 미확인 6)**이다. 현지 조합 원문 미확보·접근 차단·검색 요약만 확보한 항목은 EN을 임시 유지한다. 부분 확인 묶음은 확인된 부분만 대응하고 나머지는 EN으로 둔다. 미확인 영어를 태국 현지 표준으로 재인용하거나 추측 태국어로 자동 교체하지 않는다. 행 수는 슬래시 안 낱말 수가 아니라 개념(EN) 행 기준이다. 쟁점 표는 이 집계에 포함하지 않는다.

**화면 안 짝 맞춤:** 태국어는 동사를 명령형으로 쓸 때 별도 인칭 굴절을 붙이지 않는다. 액션 버튼은 เช็ค / เดิมพัน / คอล / เพิ่มเดิมพัน / หมอบ처럼 주어 없는 짧은 동사를 권고한다. 기록·차트 범례에서는 การเช็ค / การเดิมพัน / การคอล / การเพิ่มเดิมพัน / การหมอบ처럼 การ를 붙인 명사형으로 짝을 맞춘다. การ 접두는 편집 명사화이며 이 다섯 범례 전체를 실재 화면에서 확인한 것은 아니다. ออลอิน은 고정 액션 토큰으로 기록에도 같은 꼴을 쓴다. 혼합 전략 범례는 กลยุทธ์ผสม. 결과 열·시뮬레이터 범례의 Win / Tie / Lose는 **ชนะ / เสมอ / แพ้**라는 짧은 결과형으로 통일하고 일부만 การ 명사형으로 늘리지 않는다. 확률을 풀어 쓰는 본문에서는 ความน่าจะเป็นในการ…를 쓴다. 후보 간 최종 선택은 쟁점 표의 사람 판정 대상으로 남긴다.

### 오독 주의어·꼴 통일 규칙 (2026-10-17 · 검수장 MA-609·612 제안 반영)

1. **오독 주의어** — «คู่มือ»는 «안내서(매뉴얼·가이드)» 뜻이다. 비교하는 두 패(matchup)에 쓰지 않는다 → «ไพ่สองมือที่นำมาเทียบกัน». 허브 메뉴 Guides = «คู่มือ»(«บทความ» 아님). «มือใหม่»는 «초보자»로 읽힌다 → 다음 판은 «มือถัดไป». «เปิดไพ่»는 «패 공개» — 쇼다운 일반명으로 섞지 않는다. «ไพ่ตาย»(dead card)는 규정 용어로만 쓰고 «죽은 패·약한 패» 일반 뜻으로 쓰지 않는다.
2. **라틴 토큰과 태국어 사이 공백** — 변수·약어·고유명(`${name}`·Razz·Stud·SPR 등) 뒤에 태국어가 오면 한 칸 띄운다: `${name} ชนะ` · «Razz เท่านั้น».
3. **꼴 통일** — 너트 플러시 = «นัทฟลัช» · 169 시작 패 단위 = «ชนิด»(1,326 조합 = «คอมโบ») · call = «คอล»(글 산문의 «เรียก» 포함) · 플러시 드로 = «ฟลัชดรอว์»(«ฟลัชสี่ใบ» 지양) · 강제 베팅 = «ลงบริงอิน» · 공용 카드 = 기존 절 «ไพ่ชุมชน»(«ไพ่กลาง»과 한 글 안에서 섞지 않음). straight draw는 한 화면 안에서 «สเตรทดรอว์» 또는 영어 중 하나로만.
4. **미확인 행 확인 우선순위** — Committed · 평가/티어 5단계 · Guess/Error/Points/percentage points · 대회 상태 3 · Trips. 원문을 확보하기 전까지 EN 임시 유지 원칙(위 «미확인 = 확정 번역 아님»)은 그대로다.
5. **링크 설명은 대상 글 기준으로 다시 쓴다** — 슬러그를 다른 글로 바꾸면 앵커·카드 설명도 «그 글에 실제로 있는 절»로 좁힌다(MA-609 pushfold·M note · MA-612 우회 카드 3자리 선례).
