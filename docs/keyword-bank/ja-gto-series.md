## 4. 표기 판정 (되돌리지 마라)

1. **셋 = セット · 트립스 = トリップス · 상위개념 = スリーカード** — `ja/holdem-glossary` L47·L136 정본. 앱 라벨은 「セット/トリップス」(병기).
   ⚠ 언페어 보드(652·852·A72…)에서 앱 라벨을 인용할 땐 EN ⑩ 각주와 같은 «앱 라벨 축어 · 실제는 セット» 각주.
2. **「GTO」 라틴 + 반드시 「ポーカー」 앵커**(드라마 GTO 동음이의 — `ja-term-notation-search-match`). 「ソルバー」는 본문 정본 · 제목·H2 금지.
3. **「cb」가 검색 표기, 「Cベット」가 본문 표기** — 자사 cbet 글이 title 「Cベット」·본문 「Cベット(コンティニュエーションベット)」이므로 본문은 Cベット으로 통일, 태그에 「cb」 병기.
4. 액션·포지션·스트리트 = カタカナ 표준(`translation-terms-ja.md`). 10은 「10」(T 금지 — 단 **앱 화면 캡처와 레인지 표기(T9s 등)는 축어**).
5. 수치 = 언어 불변(반각 % · 소수점 `.` · `bb`). 「ポット」「スタック」「エクイティ実現率(EQR)」.
6. 문체 = です/ます · 두괄식 · 1인칭 최소(경험담은 관찰 서술) — `local-voice/ja-jp.md` §2.
