# pl 포커 용어·표기 브리프 (번역 착수 전 웹리서치 결과)

> 대상 = **폴란드어(pl, Polski)**. 폴란드 포커 글로시(pokerlistings.pl · pokerstrategy.pl/pl · ggpoker pl · pokertexas.net · zasady-pokera.pl · gamedesire.com/pl · sts.pl/blog) 기준. 폴란드는 **고유 포커 용어 확립**. ★**직역 아님 — 현지 맥락 재구성**.

## ⚠️⚠️ 치명 함정 (§13급 — 반드시 주의)
1. **Poker = Straight Flush!** 폴란드어에서 "poker"는 게임 이름이자 **스트레이트 플러시 족보명**(strit w kolorze). Royal Flush = **Poker królewski**. quads 아님!
2. **Kareta = Four of a Kind**(포카드).
3. **Kolor = Flush** (kolor=색/무늬도 됨 → 문맥 구분). flush 뜻일 때 족보 Kolor.
4. **Strit = Straight.**
5. **홀덤 순서 = Full > Kolor**(풀하우스 > 플러시, 폴란드 공식 hierarchy도 full > kolor로 홀덤 표준과 동일 ✓).
6. 확정 hierarchy: **Poker królewski > poker > kareta > full > kolor > strit > trójka > dwie pary > para > najwyższa karta.**

## 용어 (현지 관습)
- **족보 (폴란드어 표준명, 첫 등장 시 영어 병기)**:
  - Royal Flush → **Poker królewski**
  - Straight Flush → **Poker** ⚠️(strit w kolorze) — 첫 등장 "Poker (straight flush)"로 병기 권장(게임명 혼동 방지)
  - Four of a Kind → **Kareta**
  - Full House → **Full**
  - Flush → **Kolor** ⚠️(flush)
  - Straight → **Strit**
  - Three of a Kind / set → **Trójka** (set = set)
  - Two Pair → **Dwie pary**
  - One Pair → **Para**
  - High Card → **Najwyższa karta** (또는 wysoka karta)
- **액션**: check → **czekać / czek**, bet → **postawić / zakład**, call → **sprawdzić**, raise → **przebić / podbić / przebicie**, fold → **spasować / pas**, all-in → **all-in / va bank**. 첫 등장 후 자연스러운 쪽.
- **블라인드**: Blinds → **blindy / ciemne**, Small Blind → **mały blind / mała ciemna (SB)**, Big Blind → **duży blind / duża ciemna (BB)**. 영어 SB/BB 병기 흔함.
- **스트리트/구조**: preflop, flop, turn, river 그대로. runda betowania/licytacji(betting round), karty wspólne(community cards), karty zakryte(hole cards).
- **핵심 명사**: card → **karta**, hand(패) → **układ / ręka**, hand rankings → **układy / hierarchia układów**, dealer → **rozdający / dealer**, button → **button / przycisk (BTN)**, pot → **pula**, main pot → **główna pula**, side pot → **pula boczna / side pot**, kicker → **kicker**, showdown → **showdown / odkrycie kart / vskrycie**, suit → **kolor (masc)**, stack → **stack / stos żetonów**, chips → **żetony**, Bluff → **blef**, ante → **ante**.
- **포지션 약어는 영어**(첫 등장 병기): UTG, CO(Cutoff), MP, HJ, SB, BB, BTN.

## 표기 (⚠️ 유럽식 — 러시아/프랑스와 유사)
- **숫자 = 폴란드식**: 천단위 **공백**(spacja) → `1,326`→**`1 326`**, `198,000`→**`198 000`**, `1,300`→**`1 300`**. ⚠️마침표·콤마 천단위 금지. 소수점 **쉼표(,)** → `2.5`→**`2,5`**, `2.7:1`→**`2,7:1`**, `0.84`→**`0,84`**.
- **퍼센트**: `35%` 붙여쓰기 관습(소수 `0,84%`).
- **§13 값 자체는 불변, 구분자·공백만 폴란드식.** 라틴 숫자(0-9).
- **카드 표기 라틴 유지**: `A♠`, `K♥`, `10♦`, 보드 그대로. 무늬 기호 ♠♥♦♣ 그대로(족보 Kolor와 무늬는 문맥 구분).
- **화폐**: `$` 그대로(§13 보존 — zł/PLN로 바꾸지 말 것).

### 굴절·수 일치 규칙 (2026-10-17 · 검수장 MA-603 제안 반영)

1. **street = 남성 명사로 굴절한다.** ten street · na każdym streecie · na streecie z zakładem · kolejne streety · jeden lub dwa streety · na późniejszych streetach · z wcześniejszego streeta(단수 생격). 여성·무굴절(«na każdej street») 금지. 거리 행 위치 표현은 na flopie · na turnie · na riverze · przed flopem.
2. **«영어 유지» ≠ 굴절 금지.** 영어 낱말을 그대로 써도 폴란드어 격어미는 붙인다 — solvera(선례) · set miningu · tripsa · pierwszy re-raise(남성) · connectorów.
3. **percentage points** — 같은 화면에서 «pp»로 통일하거나 punkt procentowy(punkty procentowe)로 풀어 쓴다. 한 페이지 안에서 두 꼴을 섞지 않는다.
4. **숫자를 받는 템플릿**은 1 / 2–4(12–14 제외) / 5+ 세 갈래로 분기하거나, 분기가 안 되는 자리는 «라벨: {n}» 꼴로 쓴다(예: «Rąk: {n}» · «(outy: {n})» · 동사 pasuje/pasują).
5. **Zasada 2 i 4** 순서를 고정한다(«4 i 2» 금지). **Amount to call = Kwota sprawdzenia**(pl glossary 용례).

### 쟁점(사람 판단 필요)

- **미확인·부분 확인 라벨:** 일반 UI, solver 고급 설정·가중치·EV loss·실행 조작, 차트 강도 등급은 후속 원문 또는 폴란드어 사용자의 판단이 필요하다. 부분 확인인 대회 상태 묶음과 Clear all도 포함한다. 이 문서만으로 pl UI 현지화가 전부 끝났다고 보고하지 않는다.
- **raise와 reraise:** 기존 정본의 raise = przebić를 보존했다. 새로 읽은 PokerStrategy Raise 원문은 podbicie와 reraise(przebicie)를 구분한다. 기존 기본값 변경 여부는 사람 판단이며, 이번에는 Przebij/Przebicie로 UI 문법 역할만 정했다.
- **showdown 기존 오타 후보:** 기존 절의 vskrycie는 이번 폴란드어 원문에서 확인하지 못했다. 기존 절은 수정하지 않았고 새 UI는 Showdown으로 한정했다.
- **suited board와 보드 분류:** 홀카드 suited·보드 suited를 같은 말로 자동 번역하지 않는다. monotone·two-tone·rainbow·paired의 실제 필터 조건은 소스 의미를 보존한다. 영어 유지된 분류가 모두 현지 우세를 뜻하는 것은 아니다.
- **솔버 일반명과 고유 기능명:** trener GTO·spot·node locking 등 용례가 있어도 Study Spots / Flop Study / Daily Puzzle의 pl 공식 이름이 결정된 것은 아니다. Range Craft에서 węzeł·drzewa decyzyjne·blokowanie węzłów도 관찰했으나 한 사이트만으로 널리 쓰는 대체어라고 판정하지 않았다.
- **수치·의미·서식 경계:** equity·승리 확률·장기 win rate·EV·ICM 가치를 분리한다. 원문 사이트의 수치·수식·추천 전략은 채택하지 않았다. 출처의 PLN·USD·유럽 통화 관습은 기존 $ 유지 결정을 바꾸지 않는다. 폴란드식 소수 쉼표는 표시용이며 solver 직렬화 입력 문법까지 바꾸는 지시가 아니다.
- **대회 상태·출처 품질:** PokerStars의 Ogłoszony는 발표 상태라 Upcoming 대체어로 확정하지 않았다. Bot Verification만 열린 PokerTexas winrate·PokerTracker 페이지, 검색 요약만 남은 페이지는 증거로 채택하지 않았다. 출처 페이지 자체의 전략·정의 오류 가능성도 낱말 선택과 분리한다.
