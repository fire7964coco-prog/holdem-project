## 1. X4 — `glossary` HJ 분류 (8로케일 **16곳**)

좌석 수를 직접 세어 판정을 재확인했다:
**UTG(1)·UTG+1(2)·UTG+2(3)·LJ(4)·HJ(5)·CO(6)·BTN(7)·SB(8)·BB(9) → HJ = 9석 중 5번째 = 정중앙.**
후반은 CO(6)부터다. `ja/positions` 가 그 수를 본문 표에 직접 적어 뒀다(`5番手`).
→ **새 값 0.** 각 로케일 `positions` 의 분류어를 그대로 옮겼다.

⚠ **LJ 행도 함께 닫았다** — 지적대로 HJ를 Middle로 고치면 LJ를 「중후반」이라 부를 근거가 사라진다.
**8로케일 × 2행 = 16곳.**

🪶 나는 08-18 앞 회차에서 `positions` #62(6맥스 「뒤에 남은 상대」)를 **같은 좌석 수 검산**으로 닫았다.
같은 표가 두 축을 연달아 판정한 셈이라, `positions` 를 이 클러스터의 **좌석 분류 정본**으로 굳혀도 되겠다.

## 3. X1 — 철회를 받고, 남은 하나는 «귀속»으로 닫았다

### 🟢 철회 수용

`position-play` 65–75%(IP 한정 평균)와 `continuation-bet` 55–70%(포지션 무관 전체 평균)가
**산술적으로 공존**한다는 재판정이 맞다 — IP 65–75 + OOP 40–50 을 섞으면 55–70 이 나온다.
**「3값 충돌」은 조건이 다른 값을 같은 칸에 놓은 오독**이었다.
🪶 이건 내가 에퀴티 실현율에서 겪은 것과 **거울상**이다. 거기선 두 밴드가 «공존 불가»여서 결함이었고,
여기선 «공존 가능»이라 결함이 아니다. **둘 다 산수로 갈렸지 값 판단으로 갈린 게 아니다.**

### 🔴 값을 고르지 않았다

남은 충돌(드라이 IP: `continuation-bet` 70–100% ↔ `strategy` 60–80%)에서
**두 값 다 원장 UNVERIFIABLE 이므로 정본을 «고르는» 것 자체가 RULES §4-1 위반**이라는 판단에 동의한다.

→ **귀속으로 닫았다.** `strategy` 는 다섯 결정을 훑는 개요이고 그 절이 이미 `continuation-bet` 으로 링크한다.
**개요에서 밴드를 빼고 소유 글로 넘겼다**(불릿 + FAQ · zh-hant 는 FAQ 가 없어 1곳, 나머지 7로케일은 2곳).

**결과: 밴드를 갱신할 자리가 32곳 → 1곳.**
🪶 `position-play` 65–75% · `continuation-bet` 55–70% 는 **자산이라 안 건드렸다**(검증에 보존 항목으로 넣었다).
