## 1. 무엇이 바뀌었나 — 컨셉 전환

**후**: **"하는 방법·룰·대회·전략"이 본체.** 법은 그 안에 섞이는 흥미로운 팩트.

### 왜 바꿨나 (사용자 지시 요지)
- 사람들이 궁금한 건 **하는 방법·규칙·대회·전략**이다. 합법 여부는 각자 판단할 몫이고 우리가 개입할 자리가 아니다.
- **법 얘기를 빼라는 게 아니다.** "텍사스엔 카지노가 없는데 회원제 클럽이 있다더라" 같은 **특이하고 새로운 사실은 기삿거리**고 트래픽이 된다. 경고문이 아니라 정보로.
- **법조문 출처는 남긴다.** 다만 본문에 많이 넣지 마라 — 아무도 안 궁금해한다. **구글·GPT에 보여주는 신뢰 신호**다. 넣더라도 FAQ나 H2 하나에 몰아라.
- 포커가 마인드스포츠로 논의되는 시대에 "도박" 프레임은 브랜드에 역효과.

### 전환의 결정적 증거
사용자가 **"WSOP 같은 대회도 미국에선 불법이냐"**고 물었다. 우리 글 12편이 WSOP를 긍정적으로 다루고 있는데도 그런 의문이 든 것 = **13편을 읽고 머릿속에 남는 그림이 "안 되는 것들의 목록"**이라는 뜻. 개별 글은 정확했지만 총합이 잘못된 인상을 만들었다.

## 5. 품질 관리 — 이번에 잡힌 오류들

### 검수가 잡은 내 오류
| 오류 | 성격 |
|---|---|
| **MGM Grand를 "운영 안 함"으로 서술** | 공식 페이지 404는 **사이트 개편**이었고 룸은 운영 중. "공식 페이지 없음 ≠ 폐업" |
| **"신고하면 원천징수 정산 가능"** | 비거주자 30%는 **총액 기준 확정 과세**라 환급 불가. 독자가 헛돈 쓸 뻔 |
| **WSOP 통화 규정을 규정보다 엄하게** | 실제는 "한 테이블 거리"면 되는데 "구역을 나가야 한다"로 씀 = 겁주기 |
| **WSOP 토너먼트 규정을 "포커 전체"로 확대** | 스코프 오류. FAQ에서 특히 심했음 |
| **caja(환전)와 mostrador(등록) 혼용** | 초행자가 환전 창구에서 대기 등록을 시도할 수 있었음 |
| **100BB를 "최소 바이인"이라 호칭** | 실제 $1/$2 최소는 $40~100, 100BB는 오히려 최대인 방이 많음 |

### 내가 스스로 잡은 것
- **URL을 추측해 만들었다** — Orleans·Golden Nugget 주소를 지어냈고 둘 다 404. **조사가 실제로 연 URL만 쓴다**로 규칙화.
- **근거 깨진 값을 헤드라인에 썼다** — 베가스 "$100 최저 바이인"의 근거 PDF 추출이 깨져 있었음 → South Point 기준 $1/$2로 재구성(히어로 이미지까지 재생성).
- **findlaw가 HTTP 200으로 404 페이지를 반환** — C.R.S. §44-30-809 검증 실패 → **인용 자체를 포기**.
- **BLS 임금 데이터 접근 실패**(403 + Wayback 미보관) → 팁 글에서 **수치를 쓰지 않음**. 오히려 "0.5~2%"를 규칙처럼 단정한 경쟁 글보다 정직해짐.

### 심판이 검수자를 뒤집은 사례 (2회)
1. **LA·NV sweepstakes** — 검수자가 "LA는 금지 아님·NV는 금지함"이라 지적 → **둘 다 오판**. LA는 Act 182로 금지 맞고(법문에 "sweepstakes" 단어 없이 *dual-currency system*으로 포섭), NV 근거로 든 **AB 380은 정신건강 법안**이었다.
2. **BetRivers 미시간 포커** — 내가 MGCB 목록의 누락을 근거로 "포커 없음"이라 고쳤는데, MGCB **자체 보도자료**에 승인이 축자로 있었다. 목록의 누락을 "부재의 증거"로 취급한 내 잘못.

> **원칙**: 검수 지적도 내 판단도 **원문이 심판**이다. 확인 없이 반영하지 않는다.

## 6. 현지어 문제 — 원인과 조치

사용자가 문장이 **"번역 느낌"**이라고 지적했다.

**원인**: `docs/local-voice/es-mexico.md`·`es-latam.md`가 **7/25에 이미 만들어져 있었는데 es-US 스프린트 내내 한 번도 열지 않았다.**

파일에 있던 것: `¿cómo le hago?`의 여격 `le`가 멕시코 표식 / tilt=**calientón** / 탈락=**quedó tronado** / 드로우=**traigo proyecto de color**(동사형) / ★**`póquer`(q 철자)는 스페인 표식이라 멕시코 타깃엔 금지**

### ★구조적 발견 — H2 형태가 틀렸다
파일에 이렇게 적혀 있었다: **LATAM 교육글은 본문 H2가 명사형이고, 질문형(¿…?)은 제목·FAQ에만 쓴다.** 미국식 질문형 H2 남발과 대비된다는 기록까지 있었다.
→ 그동안 쓴 글들은 전부 미국식이었다. **신규 3편부터 본문 H2를 전부 명사형으로 전환**(질문형 0개). 검수자가 *"PokerStars Learn LATAM 관행과 정확히 일치"*로 확인.

### 교정 실적
- 첫 방문 글: **30건 + 재검수 8건**. 현지어 판정 **9/10** ("이건 멕시코 사람이 쓴 글로 읽힌다")
- 대표 교정: `apuntarse`→**anotarse**(7곳) / `se abre un asiento`(직역)→`se desocupa un lugar` / `de toda la vida`(스페인 레지스터)→`las de siempre` / `en un solo viaje`(*trip* 직역)→`movimiento` / `al fondo`→`hasta atrás` / `bolsillo`→`bolsa`
- **교정 누락 사례**: `en un solo viaje`를 본문에서만 고치고 **FAQ에 leftover**로 남겼다 → 표현 교체 시 전체 검색 필수

### ★미국 편향 — 재검수 최대 지적
독자 상당수가 멕시코 본토인데 절차·수치가 **전부 미국 기준**이라 자기 돈으로 환산이 안 됐다. 세 곳 로컬화:
- **페소 블라인드**: 멕시코 소액 테이블은 10/20·25/50 페소 → 100BB 규칙 적용 시 $2,000~5,000 MXN
- **입장 절차**: 멕시코는 **INE + 입구 등록**이 미국보다 앞단
- **대기명단**: 미국은 Bravo 앱, **멕시코 살라 다수는 WhatsApp 그룹**
