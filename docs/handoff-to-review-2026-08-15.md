### 2-2. 1차 출처로 **축어 대조까지 끝낸** 항목
재조사에 시간을 쓰지 마라. 조항 번호는 `pdftotext -layout` 추출 기준 행 번호다.

**2026 WSOP 룰북** (`wsop.gg-global-cdn.com/wsop/pdfs/2026-WSOP-Tournament-Rules.pdf`)
- **Rule 5 (Fees)** — 「additional **2% fee** … Visa, Mastercard, Discover, American Express, **or PayPal**.
  **No fees will be applied to Debit Card purchases.**」 → 룰북 전문에 **「3%」는 0건**
- **Rule 4a** — 카드 한도는 **이벤트 바이인 기준**. 「may use a credit / debit card to register for the
  **$10,000.00 Main Event** … but **may not** … for the **$50,000.00** Poker Player's Championship」
- 참가 요건 = **21세 + 신분증**(L15), 시민권·비자 요구 없음
- 비시민 ID에 ***Matrícula Consular Card (Mexico only)*** 명시(L200) · 주소 없으면 2차 ID(L201)
- 실물카드 필수·가상카드 불가·ID와 카드 명의 일치(L69·L73)
- Caesars Rewards + WSOP LIVE **둘 다 필수·무료·any WSOP Event**(L61-63) · 최초 1회 **1시간 전**(L74)
- 검증 장소 **Versailles Ballroom**(Paris 컨벤션 구역, L69·L75) · 회장 Paris+Horseshoe(L3·L8)
- **ACH = US 전용**(b항) / **Luxon Pay = Non-US 전용**(d항) / PayPal·MoonPay엔 거주 제한 **없음**
- 세금은 「참가자 부담」까지만(L193·L407) · 시즌 **May 26 → August 5, 2026**(L11)

**IRS Publication 515** (`irs.gov/pub/irs-pdf/p515.pdf`)
- 비거주 외국인 도박소득 **30% 원천징수**
- 조약 면제국 목록을 **직접 세어 25개국** — 스페인어권은 **España 하나**(México·Colombia·Argentina 없음)
- 블랙잭·바카라·크랩스·룰렛·빅6는 비과세지만 **포커는 아니다** · 헝가리·러시아 조약은 2024년 실효

**Natural8 Country Exclusives** (공식 페이지)
- 표 헤더가 **「Nationality」**, 행이 **「Taiwanese*」** · FAQ에 「What if I'm **not a local resident**?」가 **별도 문항**

  → **$1,684와 $1,703은 둘 다 맞다**(NT$ 기준 패키지 공시값 vs KRW 기준 바이인). 🔴 **통일하지 마라**

## 3. 요청 — 기계가 원리상 못 잡는 것 넷

### 🥇 ① 2차 교열 (diff 기반) — 가장 값이 크다
`git diff 5f28b42a..aabb79b0`를 **최종본 대신** 보고 판정해 주십시오.
물어야 할 것은 「이거 괜찮나」가 아니라 **「이번 편집이 무엇을 깨뜨렸나」**다.
- 이번 세션은 **수치·문장을 6로케일 21곳 규모로** 바꿨고, 이 레포는 「수정이 새 결함을 만든」 이력이 누적돼 있다
- 🔴 각 지적에 **①원본 유래 / ②이번 편집 유래**를 표기해 주십시오
  (안 하면 diff 렌즈는 원리상 「이번 편집 결함」만 올려 비율이 왜곡된다)
- 특히 볼 자리: 새로 넣은 문장이 **기존 문단과 축어 중복**을 만들지 않았는지,
  통화·단위 변경이 **그 값을 쓰는 다른 문장**(배수·합계)과 어긋나지 않는지

### 🥈 ② D유형 — WSOP 결제 안내가 실전에서 맞나
숫자는 룰북과 맞췄지만 **조언으로서 옳은지**는 별개다.
- 「**직불카드는 수수료가 없으니 직불로 내라**」 — 실제 현장에서 해외 발행 직불카드가 통하는가?
  (한도·해외결제 차단·DCC 등으로 오히려 막힐 여지가 있다면 그게 D유형이다)
- 「**메인이벤트는 카드로 한 번에 결제된다**」 — 룰북 예시는 그렇게 읽히는데 현장 운영이 다른가?
- 「**Luxon Pay가 비미국 거주자의 경로**」 — LATAM·아시아에서 실제로 계정 개설이 되는가?
- 이 셋은 **여행 계획과 지출을 바꾸는 조언**이라 틀리면 수치 오류보다 해롭다

## 4. 🔴 의도적으로 뺀 것 (지적 대상 아님)

프로토콜의 「의도적 제외 목록」이다. **여기 적힌 것은 결함이 아니다.**

1. **`$1,684` vs `$1,703`을 통일하지 않았다** — 각각 NT$ 기준 패키지 공시값과 KRW 기준 바이인이다
2. **`ept-barcelona`에 `€10,300`이 남아 있다** — 그건 **EPT High Roller 바이인**이고 EUR가 맞다.
   USD로 바꾼 건 **Gold Pass 가치**뿐이다(숫자가 같아 헷갈리기 쉬운 자리)
3. **`casinos.at` 데이터를 지우지 않았다** — 거짓이 되는 건 «우리가 열람했다»는 주장이지 데이터가 아니다.
   열람 주장만 빼고 「자동 접근 차단으로 대조 불가 → 출발 전 직접 확인」으로 바꿨다
4. **`masterUpdated`를 일부만 올렸다** — 전문 1:1 대조를 마친 로케일만 올렸다.
   de·id·pt에 필드가 없는 것은 «추적 불가»를 그대로 남긴 것이지 누락이 아니다
5. **ko `holdem-tournament`이 없다** — 이 글은 EN 독립 필라라 한국어판이 존재하지 않는다
6. **`wsop-2026-tournament-guide`가 de·id·pt에 없다** — 6개 언어로만 발행된 글이다
7. slug·이미지·구조는 불변 · 본문에 백틱 없음 · 출처 섹션 형식은 기존 규격 유지
