## 3. 편집·검증 상시 규율 (GTO·다국어 공통)

- **미러 작업 4+1단계**: ①KO 확정 → ②전 로케일 grep(표기 변형 포함) → ③로케일별 재저작 →
  ④게이트 재실행 → **⑤편집한 문단 다시 읽기**(수정이 결함 주입 공정이다).
- 🔴 **미러 커밋은 날짜 필드를 건드리지 않는다**(선례 `97e46572` · `c2ccc049`). 특히
  **`masterUpdated`를 올리면 «EN 최신과 동기화됨»이라는 거짓 신호**가 된다 — 미러는 명제 한 건만
  옮겼을 뿐 나머지 EN 드리프트(경험담·FAQ 개정 등)는 그대로다. 올리는 순간 다음 회차가
  드리프트를 못 본다. **게이트가 계속 «masterUpdated < EN»을 보고하는 것이 의도된 상태다.**
- 🔴 **미러 자리 수는 로케일마다 다르다 — «정본이 N자리니까 전부 N자리»라고 가정하지 마라.**
  번역이 재저작이라 그 문장 자체가 없는 로케일이 흔하다(Rule 16 미러: 대부분 3자리인데 EN은
  4자리, ja는 2자리였다). **파일을 열어 «그 명제를 말하는 자리»를 세라** — 기계 치환은 오작동한다.
- **2차 교열 패스는 선택이 아니다** — 여러 회차에서 «그 회차 수정이 만든 결함»이 두 자릿수로 나왔다.
  교열은 «남의 수정»이 아니라 **«내 수정»**을 본다.
- **명제를 고칠 땐 grep 씨앗을 만들어 KO·EN 양쪽 + 여섯 층**(본문·FAQ·tldr·desc·표·헤더)에 걸어라.
  줄 단위 수정은 같은 명제의 다른 사본을 남겨 자기모순을 만든다(M-025 신설 90건의 원인).
  형제 편에도 같은 값·같은 태그를 grep(`grep -c "<고친값>" lib/posts/<형제들>.ts`).
- **위치 참조(「위 표」·「두 문단 위」) 금지** — 수정이 고아 참조를 만든다.
- **«수치를 빼는» 수정이 가장 위험하다** — 뺀 자리에 절대 명제를 넣으면 더 센 거짓이 된다.
- **범위는 늘 「A%~B%」로 써라**(앞 숫자에도 %) — 안 붙이면 `check:gto` 판정 정규식 밖으로 빠진다.
- **본문에 🔴 금지 — ⚠를 쓴다.** 🔴는 헤더 주석 전용 «되돌리지 마라» 신호다.
- **EN 게이트는 `--locale=en`**(`audit:hard --slug=`는 KO를 잡는다) · `check:gto` 🔴 0 아니면 배포 금지.
  `check:gto`의 「N 일치」는 **A(발행 편수×로케일×3지표)+B(ko 외 로케일 수)** 산수로 내역을 직접 세라.
- **`lib/posts-en/index.ts` 등록은 import와 배열 둘 다** — 배열을 빠뜨려도 에러가 안 난다.
  Edit 도구로 직접 넣고 판정은 빌드 로그의 `intl posts` 개수로.
- **형제 글 링크는 발행 즉시 양방향** · 인용은 줄번호가 아니라 앵커 문구로.
- **적대 렌즈 지적은 전건 원문 판정 후 강도를 교정해 반영** — 방향이 맞아도 크기는 틀릴 수 있다.

## 6. 인프라·게이트 노트

- **DataForSEO**: `.mcp.json`에 `dataforseo` 등록(자격증명 = `.env.local`의 `DATAFORSEO_LOGIN`/`_PASSWORD`).
  🔴 MCP는 세션 재시작 후 붙는다 — 그전엔 `curl` REST 직접. 잔액은 대시보드.
- **`check:meta-lang`**(postbuild): 비한국어 페이지의 **자리 10종**에서 한글을 잡는다 —
  `<title>`·`og:title`·`og:description`·`twitter:title`·`twitter:description` +
  🆕 `application-name`·`author`·`keywords`·**스킵링크**(`a[href="#main-content"]`) · 🟠 `og:site_name`.
  (2026-08-25에 5종 → 10종 확장. 그전의 «4종 사각지대» 서술은 해소됐다 — 커밋 `ac5decf2`.)
  · 셀프테스트 `npm run check:meta-lang:selftest` — **검출 6 · 오탐방지 6**. 규칙을 넓히기 전에
    셀프테스트부터 세우는 것이 이 레포 규율이다(de 게이트 26건 중 20건 오탐 전례).
  · 매 실행 **자리별 커버리지**를 찍는다 — 태그가 없는 자리는 «검증»이 아니라 «미검사»다.
  ⚠ 남은 한계 — ① es 페이지에 **일본어**가 들어가도 통과한다(잡는 건 «한국어 상속» 한 유형뿐)
    ② 산출물만 본다(빌드 전엔 못 돈다)
  🔴 ③ **`vercel.json`의 `buildCommand`에 없다 → 프로덕션 배포에서는 안 돈다.**
    로컬 `npm run build`에서만 돈다(`check:hreflang`도 같다). 미결 — 핸드오프 참조.
- 🔴 **`title: { absolute: … }`를 쓸 때는 `LocaleHomeJsonLd`를 함께 봐라** — `metadata.title as string`
  캐스팅은 객체를 JSON-LD에 넣는다. `const PAGE_TITLE`로 빼서 양쪽이 같은 문자열을 쓰게 한다.
- **DOM 밖 문자열(manifest·twitter 메타·스킵링크)은 언어 검사가 통째로 지나간다** — 새 로케일 화면을
  열면 DOM 밖 문자열도 함께 점검. **주석이 있어도 강제하는 검사가 없으면 안 지켜진다 → 게이트로 만든다.**
