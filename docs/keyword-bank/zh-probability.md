## 4. 🔴 함정

1. **`胜率计算器`·`计算app`·`算牌器`·`计算器在线` = 도구 의도다.** SERP 1위가 계산기 페이지(`dongpaidi.com/calc.htm` — 실측: 한자 77자, 본문 없이 위젯만).
   **글로는 못 이긴다** → 태그에서 빼라. 메모리 `holdem-site-keyword-intent-verdict`의 zh판.
   `equity` 현행 태그 `扑克胜率计算器`는 **`德州扑克翻牌前胜率`로 교체**한다.
2. **`机率`는 이 축에서도 계속 나온다**(`outs 机率` · `拿到aa机率`). 회차 2 판정대로 **主词는 `概率`**.
   🪶 단 회차 2의 「机率=대만 표기」는 **너무 좁다** — 실측: 대륙 사이트 `moshike.com/a/782.html` 본문도
   「赢下底池的机率」로 쓴다. **판정은 유지하되 근거를 «대만 전용»이 아니라 «우리 코퍼스 主词 통일»로 적는다.**
3. **`德州撲克 outs 計算`(번체)이 `outs 德州` 시드에 섞여 나온다** — 회차 2의 `德州扑克新手ptt`와 같은 대만 오염 신호. 채택 금지.
4. 🔴 **WebSearch 요약이 공식을 틀리게 줬다**(§12-B 실증). 요약은 所罗门法则을 `4n-(8-n)`으로 적었는데
   원문(legendpoker 2851)은 **`X*4-(X-8)` = `3X+8`**이다. 요약대로면 9 outs가 37%(실제 35.0%)로 틀린다.
   **원문 직접이 아니었으면 오답을 그대로 실었다.**
5. `德州扑克概率怎么算`·`底池赔率怎么算` 같은 **「怎么算」 완전문은 자동완성에 없다** — 살아 있는 것은 명사형 `概率计算`·`赔率计算`이다.
   → 🔴 **이 클러스터의 질문형 H2는 «명사 키워드를 품은 질문»이라야 한다**(§5 참조).

  🔴 **처방 = «명사 키워드를 그대로 품은 질문형 H2»**. 예: ❌`概率怎么算？` → ✅`德州扑克概率计算怎么做？`

  키워드를 잃은 순수 질문형은 이 축에서 **손해**다.

## 7. 🪶 zh 고유 확장 후보 — 所罗门法则 (1차 출처 대조 완료)

`translation-terms-zh.md` L372가 **이미 용어로 수록**하고 있는데 우리 코퍼스에 **0건**이다. 경쟁 글 2편이 다룬다.

- 정의(legendpoker 2851 축어): *「二四法则的修正 … 两条街的时候当补牌数目大于或等于9的时候 …
  2条街的成牌概率约=[X*4-(X-8)]*1%」*, 간이형 *「(X*3+8)*1%」*.
- 🔴 **직접 검산(2026-09-07)**: 정확값 `1 − C(47−X,2)/C(47,2)`
  · X=9 → 34.97% / 二四 36 / 所罗门 **35** ✅
  · X=12 → 45.0% / 二四 48 / 所罗门 **44** ✅
  · X=15 → 54.1% / 二四 60 / 所罗门 **53** ✅
  → **补牌가 많을수록 二四法则이 과대평가하고 所罗门法则이 실제값에 붙는다**는 서술은 참이다.
- 배치: **`holdem-outs` 「二四法则」 절의 FAQ 1개**(EN에 없는 zh 고유 확장 — 회차 2의 零头 계산 예시와 같은 성격).
  🔴 EN에 없으므로 **거울쌍 갈림으로 보고하지 않는다**(§7-D 예외 · 진행 파일 §4 「고유 확장」 목록에 추가).
