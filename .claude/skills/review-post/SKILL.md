# review-post — 포스트 검수 프로토콜

HoldemMaster의 가장 잦은 작업: **특정 글 검수 → 오타·사실오류·링크·이미지 수정 → 빌드 → 배포**.
CLAUDE.md §13(포커 정확성)·§14(검수 체크리스트)·§15(이미지)의 규칙을 이 순서로 강제 적용한다.

## 0. 대상 파일 찾기 (먼저)

slug가 어느 트랙에 있는지 Grep으로 확인 — 위치마다 규칙이 다르다:
- `lib/posts.ts` = 한국어 LEGACY (구조/slug 변경 금지, **오타·사실오류·링크 수정은 허용·권장**)
- `lib/posts/[slug].ts` = 한국어 NEW
- `lib/posts-en/[slug].ts` = 영어
- `lib/posts-{ja,zh,es,pt,de,id,...}/[slug].ts` = 다국어

```
Grep: slug: ['"]<slug>['"]   → 파일·라인 확정 후 Read
```

## 1. ★ 사실 정확성 — §13 포커 핸드 검산 (1순위, 절대 스킵 금지)

> **왜 최우선**: 작성자 소개가 "WSOP·GTO·12년"으로 E-E-A-T를 강하게 어필한다. 핸드 예시 1개라도 틀리면 신뢰가 무너진다. **사실오류 1개 = 치명상.**

핸드 예시가 나오면 **무조건** 아래를 눈대중 없이 실행:
1. 각 플레이어의 **7장 나열** (홀카드 2 + 보드 5)
2. 7장 중 **베스트 5장을 명시적으로 조합** (가능한 족보 전부 비교)
3. **양쪽 베스트 5장 직접 비교** → 의도한 승자/스플릿과 일치하는지 확인
4. 함정 집중 점검:
   - 보드에 스트레이트가 깔렸을 때 홀카드가 **그 위로 더 높은 스트레이트**를 만드는가 (2026-06-23 tiebreak 사고의 원인)
   - "스플릿"이면 양쪽이 **정말 동일한 5장**인가 (한쪽이 홀카드로 개선되는가)
   - 키커: 보드 카드가 자동으로 베스트5에 들어가 키커가 바뀌는가
   - 휠(A-2-3-4-5)은 가장 낮은 스트레이트 / 무늬 서열 없음(플러시는 숫자로만)
5. 표·비율·확률·사이즈(3벳 BB, 팟오즈 %, 아웃츠 등)도 **산수 재검산**
6. 필요하면 `lib/poker-eval.ts`나 작은 node 스니펫으로 평가 — 절대 눈대중 통과 금지

전략 수치·룰 설명·토너먼트 정보(운영사·날짜·바이인)도 사실 확인. 시간민감 정보(마감·매진·자격)는 WebSearch로 실검증.

## 2. Trailing slash (301 방지)

내부 링크가 `/blog/x/`로 끝나면 301 발생 → `/blog/x`로 수정.
```
Grep: /blog/[^)"'\s]*/["')]     (glob으로 대상 파일 한정)
```
calculator/hand-chart/quiz 등은 로케일 중립 canonical(`/calculator`) — 다국어에서 `/{locale}/calculator`는 404.

## 3. 링크 유효성

참조한 slug가 실제 존재하는지 확인 (`lib/posts.ts` + `lib/posts/` + 해당 언어 폴더). 죽은 링크 = 수정.
다국어면 내부링크가 EN 마스터와 **개수(count) 패리티**인지 확인 (Related/readnext/thumb 포함).

## 4. 이미지 점검 (§9·§15)

- **깨진/플레이스홀더**: 1KB 안팎 webp = 빈 플레이스홀더(내용 없음) → 새로 제작 필요, 사용자에게 보고
- **용량**: 60KB(복잡한 인포그래픽 80KB) 초과 → 재압축 (§15 Windows 파일 락 주의: readFileSync→tmp→rename)
- **형식**: webp만 (png/jpg 금지), 1200×675, 히어로 `priority={true}`
- **alt**: 구체적 상황 묘사 (키워드 나열 금지)
- **맥락**: 이미지가 본문 내용과 맞는가 / 한글 오버레이 없는가(다국어 공용) / 인포그래픽이면 §9-1 스펠링 육안검수 (브라우저 MCP나 Read로 렌더 확인)
- **클러스터 중복**: 연관 클러스터끼리 본문 사진 재사용 금지 — 재사용 전 Read로 육안검증

## 5. 속도 (매 검수 포함 — 2026-07-03 지시)

LCP·이미지 용량·치수(CLS) 점검. 필요 시 `npm run psi <url>` (인라인 `PSI_API_KEY=... node`). 무한 CSS 애니메이션·클라 POSTS import 번들은 과거 지문 — [[perf-lessons-lcp-and-bundle]].

## 6. 메타 & 날짜

- `seoTitle` ~32자(EN ≤60) / `desc` ~95자·**160자 초과 금지**, 호기심 훅 + 키워드 (§8·§17). 정보형("OO 뜻 정리"·"총정리") 금지. CTR 좋은 훅을 정보형으로 단독교체 금지.
- 글 수정 시 `updated`(또는 `dateModified`/`masterUpdated`)를 **오늘 날짜**로 갱신 (sitemap lastmod 반영).
