## 3. 규칙 (위반 = 반려)

1. **구조 1:1** — H2 개수·순서 · 모든 `:::` 디렉티브(stripe·note·pull·compare·readnext) · 표 행/열 · `==…==`·`==g:/==r:==` 하이라이트 · FAQ 문항 수 · 본문 이미지 1장(위치까지) — EN과 **개수 동일**. 문구만 번체.
2. **내부링크 개수·대상 1:1** — `/en/blog/<slug>` → `/zh-hant/blog/<slug>` · `/en/solver` → `/zh-hant/solver` · `"thumb:/images/…-hero.webp"` 유지(시리즈 내부 썸네일은 `-en.webp` → `-zh-hant.webp`) · readnext 행 수 유지(라벨은 `[繼續閱讀]`). ✅ EN이 거는 외부 slug 10종은 전부 zh-hant에 실재한다(팩 §3) — 대체 불필요. 시리즈 13편끼리의 링크는 slug 동일.
3. **이미지** — `-en.webp` → `-zh-hant.webp`(oop·ranges 2장). alt·캡션은 번체 재저작. content에 히어로 마크다운을 **넣지 마라**(다국어 렌더러가 `post.image`를 그린다).
4. **수치·카드·확률·콤보 수 = 축어** (반각 % · 소수점 `.` · 천단위 `,` · `bb` · 카드 `A♠` 그대로 · 레인지 약호 `T9s`·`TT` 그대로 — 코퍼스 TT 18 · T9s 4). 🔴 **카드 10은 「10」으로 쓴다**(`T♠`→`10♠` · `Q-J-T`→`Q-J-10` · 앱 스팟명 「K 高帶 10 的牌面」 · 코퍼스 10+무늬 40 : T+무늬 **0** · 하이픈 보드 Q-J-10·J-10-9·10-9-8만 존재). **🔴 간체 브리프 §4-B(「T♠ · Q-T-7 · 10 금지」)와 정반대다 — 그 줄을 승계하면 13편이 대륙 글로 보인다.** 단 표·인포그래픽에 앱 화면을 «축어 인용»하는 자리(보드 헤더 `Q♠J♦T♠`는 앱이 T로 표기)는 조건표 `翻牌` 행에서 `Q♠ J♦ 10♠`로 쓰고, 이미지 alt에서도 10. 계산식 `==15.46 ÷ 13.12 = 117.8%==` 그대로. 「百分之」 풀어쓰기 금지.
5. **고지 문장 전부 보존** — «first action only / not in this solve / the study spot pre-solves the flop's first action only / cannot be confirmed here / judgment, not a figure / this section is interpretation, not a solver figure / resolved separately (re-solve) / screen values are rounded» 류는 **한 문장도 떨어뜨리지 마라**. 번역에서 가장 먼저 사라지는 문장이다(스펙 §4-A-3 조건 ③). zh-hant 고정 번역(🔴 §7 네이티브 검수 통과본 — 2026-09-03): «pre-solves the flop's first action only» → 「教學案例只算到翻牌圈的第一個動作」 · **«not in this solve»**(솔버가 안 풀었다) → 「這個數字不在這次計算裡」 · **«not one of the numbers on this page»**(이 글에 안 실렸다 — 🔴 다른 고지다, 합치지 마라) → 「這一頁上沒有這個數字」 · «cannot be confirmed here» → 「在這個畫面上無法確認」(「在這裡」는 «이 국면에서»로 읽힌다) · «judgment, not a figure» → 「這是判斷，不是數字」 · «interpretation, not a solver figure» → 「這一節是解讀，不是解算器給出的數字」 · «resolved separately (re-solve)» → 「另外單獨算一次（重新解算）」 · «screen values are rounded» → 「畫面上的數值是四捨五入過的」.
   **리드 고정문**: «Every figure below came from HoldemMaster's [free GTO solver](/en/solver), read off the study-spot output on 2026-08-19, and you can pull the same screen up with a single click.» → 「下面每一個數字都來自 HoldemMaster 的[免費 GTO 解算器](/zh-hant/solver)，於 2026-08-19 直接從教學案例的輸出畫面讀出來；你只要點一下，就能叫出一模一樣的畫面。」(🔴 링크 포함 — 날짜는 편마다 EN 값).
6. **H2 = 대만 실검색 형태** — `zh-hant-search-behavior-report.md` §6: **명사형 토픽 + 짧은 「…怎麼打？」「該…嗎？」 훅**이 본류, 풀 자연어 질문·「是什麼」 H2는 지양(단 EN이 정의형 H2인 자리 — ⑤ «What is a monotone board» · ⑧ «What is SPR» — 는 「什麼是…？」 허용 · 코퍼스 3bet 「3-bet 是什麼？」 선례). EN 질문을 **직역하지 말고** 팩 §3의 축으로 다시 묻는다. 각 H2 직후 **볼드 직답 1~2문장** 유지(EN 구조). **EN에 그 H2가 있는 자리에서만** 고정 번역을 쓴다(es ⑤ 교훈): `## What conditions produced these numbers?` → `## 這些數字是在什麼條件下算出來的？` · `## What changes at the table?` → `## 在牌桌上要改什麼？` · `## Check it yourself` → `## 自己去驗證` · `## FAQ` → `## 常見問題 FAQ`(코퍼스 42편).
7. **용어**(팩 §4 정본 + 아래 §4-B) — 牌面(board · 「公共牌」은 앱 입력 UI 인용 시만) · **乾燥 / 單色牌面（3 張同花） / 對子牌面 / 彩虹 / 雙色 / 連張 / 多變**(앱 축어 · 「濕潤」은 대비어로만) · 頂對 · 超對 · 次頂對 · 弱對 · 低對 · 未成牌 · 兩對 · **暗三條(set) / 明三條(trips)**(첫 1회 괄호 병기) · 聽牌 · 卡順聽牌 · 兩頭順聽牌 · 同花聽牌 · 後門同花聽牌 · 組合聽牌 · 同花 · 順子 · 葫蘆 · 四條 · 底池(「彩池」 금지) · 有效籌碼量 · 詐唬(bluff 병기 첫 1회) · 堅果 · **勝率實現（EQR）**(🔴 간체 權益實現 금지) · 範圍優勢 · 堅果優勢 · 個百分點(%p) · 不利位置（OOP）/ 有利位置（IP） · 盲位對戰 · 3bet 底池 · 單加注底池 · 3bet 方 / 跟注方 / 開池方(앱 축어) · 持續下注（c-bet）→ c-bet · 過牌加注 · **領先下注（donk bet，俗稱領打）→ 領打**(첫 1회 풀표기 · 본문 약칭 領打 · 검색 표면(④ title·seoTitle·H2·tags)만 領先下注 · 「驢式下注」 금지 — §4-B) · 兩極化範圍 · **阻擋牌(blocker)**(🔴 간체 阻斷牌 금지) · **籌碼與底池比（SPR）→ SPR** · MDF · EV · **解算器**(🔴 간체 求解器 금지) · **百老匯**(🔴 라틴 broadway 금지).
