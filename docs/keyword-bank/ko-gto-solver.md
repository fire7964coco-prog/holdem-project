## 5. 재현 방법

```bash
# 자동완성 (원문 JSON을 직접 파싱한다 — 요약 도구를 거치지 않는다)
curl -s "https://suggestqueries.google.com/complete/search?client=chrome&hl=ko&gl=kr&oe=UTF-8&q=<키워드>"
```
- 🔴 **`oe=UTF-8`을 반드시 붙여라 (2026-08-14 정정).** 종전 이 문서는 「`client=chrome`이면
  UTF-8이 온다」고 적어 뒀는데 **지금은 틀리다** — 응답 헤더가 `charset=EUC-KR`이라 그냥 읽으면
  한글이 전부 「Ȧ��」로 깨진다(수확 1회를 통째로 날렸다). `oe=UTF-8`을 주거나
  `new TextDecoder("euc-kr")`로 디코드해야 한다. `client=firefox`는 여전히 쓰지 말 것.
- **위치 변형 필수** — 뒤에 자모·알파벳을 붙여 캐고, 앞에도 `홀덤/포커/텍사스홀덤`을 붙여 캔다
  ([[keyword-harvest-wildcard-positions]]).
- 월간 검색량은 **라쿠키워드 MCP**로 잰다. `search-volume-history`에 `language: "Korean"`,
  `location: "South Korea"`를 주면 한국 데이터가 나온다(일본 전용이 아니다). 50개씩 묶어 던지면
  10초 안에 끝난다. `seoDifficulty: true`는 최대 60분 걸리니 SEO 난이도가 꼭 필요할 때만.
