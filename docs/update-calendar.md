## 자동 재생성 방법

①(대회 종료 → 글 갱신)은 언제든 다시 뽑을 수 있다.
`lib/tournaments.ts`의 `endDate`와 `blogLink`를 대조하고, 각 로케일에
`lib/posts-<locale>/<slug>.ts`가 있는지 보면 "어느 글이 몇 개 언어로 존재하는가"가 나온다.
새 대회를 추가하거나 새 글을 쓰면 이 파일에도 한 줄 추가한다.
