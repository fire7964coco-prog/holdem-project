# 유튜브 영상 임베드 플레이북 — 체류시간 부양 (2026-07-21 논의 정리)

> 목적: 포스팅 주제에 맞는 유튜브 영상을 임베드해 **체류시간↑ + AI 비대체 자산화**.
> "2분만 봐줘도 체류 확 뜬다"가 핵심 통찰. 정보형 오가닉을 AI가 잠식하는 시대에 영상·인터랙티브는 AI Overview가 못 뺏는 클릭 명분.

## 1. 절대 원칙 — 임베드 O / 재편집·재호스팅 X
- **iframe 임베드 = 안전**(우리가 호스팅 아님, 유튜브 표준 사용법). 위험 0.
- **남의 경기영상을 편집해 우리 서버(holdemmaster.com)에 올리는 것 = 저작권 지뢰**(WSOP·PokerGO 단속 공격적, DMCA·사이트 제재 위험). **절대 금지.**
- ★**내가 만든 편집 쇼츠**는 → **홀덤마스터 유튜브 채널에 올리고 → 그 "내 쇼츠"를 임베드.** 편집본은 유튜브 생태계(Content ID) 안에 남고, 웹사이트는 그냥 임베드 = 안전. 유출도 **우리 채널로** 흘러 브랜드↑(마케팅 플라이휠).

## 2. 영상 3종 × 적합 글
| 종류 | 어디에 | 언어 | 유출 |
|---|---|---|---|
| **① 드라마 클립**(핸드 터지는 순간) | bad-beat·cooler·bluff·유명핸드 | **언어중립 → 전 언어 공유**(이미지처럼) | 남의 채널 |
| **② 설명 영상**(잘 가르치는 영상) | 룰·전략·족보 | **언어별**(EN=영어 유튜버, JA=世界のヨコサワ 등 현지 대형) | 남의 채널 |
| **③ 내 쇼츠** | 고트래픽 글 우선 | 내가 제작 | **우리 채널** ✨ |
- 적합도: 드라마·정의 글 = ✅ 최적 / 룰·족보 = 🟡 데모용 / **순수 계산·전략(팟오즈·ICM·레인지) = ❌**(우리 표·계산기·퀴즈가 나음).

## 3. 안전 워크플로우 (환각 방지 = 우리 방식의 핵심)
1. **실제 검색으로 후보 URL 확보**(WebSearch, 슬러그 추측 금지). 공식/대형 채널 우선(WSOP·PokerGO·PokerStars·partypoker·Upswing·JLittle) = 내구성.
2. **transcript(자막)로 검증** — 사용자가 붙여넣거나(유튜브 자막 패널) 판정. 자막으로 잡히는 것: ①§13 정확성 ②주제 적합 ③하이라이트 구간(타임스탬프) ④광고·삼천포.
3. **사람 눈이 최종** — 화질·에너지·비주얼 임팩트는 LLM이 못 봄 → 최종 3~5편은 사람이 재생해 낙점.
- ★단일 명장면 클립 > 컴필레이션(Top5/Top10). 컴필은 "이 섹션=이 순간" 정밀매칭이 안 됨.

## 4. 가드레일
- **성능(CWV 사수)**: 유튜브 iframe 무거움 → **반드시 lite-facade**(썸네일→클릭 시 로드). 안 그러면 우리가 고친 LCP·CLS 재악화.
- **본문 = 여전히 본체**: AI/LLM은 임베드 영상 못 봄 → 정보는 본문·캡션이 지고 영상은 "체류 보너스". **VideoObject 스키마는 넣지 말 것**(우리가 소유자 아님).
- **타임스탬프**: `?start=초&end=초`로 임팩트 구간만 재생 = "하이라이트 효과"를 저작권·편집 0으로. "구간 보기" 텍스트 링크로 클릭재생 유도 → 이탈 방지.
- **링크 썩음**: 임베드도 원본 삭제되면 깨짐 → 컴포넌트에 **폴백**(삭제/임베드불가 시 대체) + 주기 점검.

## 5. 컴포넌트 (렌더러 추가 예정)
- `:::youtube[영상ID][start][end]:::` (가로) / `:::short[영상ID]:::` (세로 쇼츠) — lite-facade.
- 기존 `:::readnext` 등과 같은 디렉티브 방식. 전 언어·전 글 일관.

## 6. LLM 주의 (2026-07-21 Gemini 검증 교훈)
- Gemini가 준 영상 **ID 3개는 검색 대조 결과 전부 실재·정확**(환각 아님). → LLM 추천 ID를 무작정 불신 X, **검색으로 대조하면 됨.**
- 그러나 **타임스탬프·구간별 내용 묘사는 LLM이 못 봄 → 환각/공란**. Gemini도 구간을 빈칸("****")으로 남겼음. **정확한 start/end는 반드시 transcript/사람눈으로 확정.**
- 즉 LLM(나·Gemini) = 영상 찾기·프레이밍용, **타임스탬프·정밀 매칭은 검증 단계 필수.**

## 7. 판정 로그 (진행)
- **bad-beat 파일럿 확정** ✅: `YfmtSw1xfRU`("Royal Flush vs Quad Aces 2008 WSOP", 원본 방송 ≈1:34) — 우리 글 헤드라인 핸드(馬渕). **start=0 / end≈52**(카드공개+리액션+"that's a bad beat" 대사, 0:52 이후 Raymer 잡담 컷). 배치 = "가장 유명한 배드비트" 섹션. ⚠️해설의 "1 in 2.7 billion"은 방송 과장 → 본문에 옮기지 말 것.
- **전략글용 킵**: `8NmUlzIUe8E`(Alec Torelli, Duhamel vs Affleck 8분 분석) — bad-beat 드라마엔 ❌(talking-head), **3bet/when-to-fold/icm 글에 "프로 핸드 분석"으로 ✅**.
- bluff 후보(미검증 구간): `Noo4Ua7Jmc0`(partypoker), 단일 명장면(Ivey `npeq48Idp08`)이 섹션매칭엔 더 나을 수 있음.
