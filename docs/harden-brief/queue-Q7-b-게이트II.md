## 2. G1 셈의 단위 — 산식

```
hit = 블록 ↔ 절 본문(블록 제외)의 최장 공통 부분문자열   (장식 제거 · 공백 전삭 후)
eff = 표의문자·가나·한글만 센 길이(cjkLen)   /   en은 알파벳만(enLen)
raw = hit의 문자 수(그대로)

🔴 echo  ⟸  (eff ≥ MIN_LCS[loc])  또는  (eff ≥ RAW_FLOOR[loc] && raw ≥ RAW_MIN[loc])
           그리고 나열·공식이 아니고, 고유명사 면제에 안 걸린다
```
- `MIN_LCS` = 기존값 유지(zh·zh-hant·ja 18 · ko 14 · en 35).
- 신설 `RAW_MIN` = **ja·zh·zh-hant 18 · ko 14 · en 35**(원문 기준) · `RAW_FLOOR` = **ja·zh·zh-hant 12 · ko 9 · en 20**.
- 🔴 **`RAW_FLOOR`가 「숫자·라틴만 겹치는」 오탐을 막는 자리다**(`25/50→50/100→100/200` = eff 0 → 통과). 이 하한을 0으로 내리지 마라.
- 첫 실행 전건 판정 후 값 조정(아래 §5에 결과를 적는다).

## 3. G2 개수·포인터 — 회차 12·13 스캐너의 기계화

**① `count` 1차 신호(H2 개수어)** — 절 제목에서 `N選 / Nつ / N個 / N種類 / Nパターン / Nステップ / N通り / N가지 / N개 / N단계 / N个 / N种 / N大 / two–ten + ways|things|mistakes|rules|steps|reasons|questions` 를 뽑는다.
**② `count` 2차 신호(블록 자체 선언)** — 같은 패턴을 **블록 본문**에서(회차 13 스캔 ②. 결손 4건 중 2건이 ①과 중복이었다).
**③ 열거 수 세기** — 🔴 **회차 13 브리프가 「스캐너는 항목을 세지 못한다 · 13건 전부 손으로 셌다」**고 적은 자리다. 기계가 셀 수 있는 세 가지만 센다:
   - 볼드 런 `**…**` 개수 · 구분자 런(한 문장 안 `、，,・･/` 로 갈린 조각 수) · 번호 마커(`①②③` · `1つめ` · `1.`)
   - 셋 중 **최댓값**을 «기계가 센 열거 수»로 삼는다. 🔴 **셋 다 0이면 «미판정»으로 출력한다**(0건으로 흘리지 않는다).
**④ `pointer` 신호** — `下の表 / 以下の / 次の / この節 / 表のとおり / 見下表 / 如下表 / 아래 표 / see the table below` 등.
   판정 3단(정본 = ja §5-I 5 · §3-M 7) — 🔴 **결손**(포인터가 마지막 문장이 아니다 = 답이 포인터 뒤에 있다) · 🟠 **의존**(블록 어두가 선행사 없는 지시어) · ✅ **브리지**(**마지막 한 문장만** 표 안내 **이면서** H2가 약속한 개수어 N이 블록 안에서 충족).
   🔴 **브리지 정의를 넓게 잡으면 오통과가 난다**(§3-M 7 — ja가 2자리를 오통과시켰다).
**⑤ 판정 등재** — 회차 12가 원문 판정으로 닫은 **✅ 브리지 9 · 🪶 오탐 4**와 회차 13의 ✅는 `JUDGED`에 근거와 함께 박는다. 등재하지 않으면 매 회차가 같은 자리를 다시 판정한다(`check:structure`의 `ALLOW`와 같은 장치).
🔴 **정밀도 기대치**: 회차 11 첫 주사 42히트 중 **29 오탐** · 회차 12 22히트 중 **13이 ✅/🪶** · 회차 13 ① 31히트 중 결손 **6**. → **🔴을 쓰지 않는다.** 전부 🟠 «후보»이고, 등급 승격은 실측 정밀도가 서고 나서다.

## 4. G3·G4·G5

- **G3** `classify()`에 `code`: 스탬프 제외 잔여를 `/\.trim(?:Start|End)?\(\)/` 등 **메서드 호출 골격**만 지운 뒤 `bare()`가 같으면 `code`. 🔴 **지우는 것은 «호출 문법»뿐이다** — 본문에 `.trim()` 문자열이 들어갈 길은 없다(포스트 본문 백틱 금지 §12-A). `cosmetic`과 같은 취급(🔴 아님) · 커버리지 줄에 별도 계수.
- **G4** `measure()`에 `linkn`(정규식 전건 매치 수) 추가 → `deficit()`에서 `en.linkn - loc.linkn > 0`. **첫 실행 실측 = 결손 21쌍**(ar 7 · zh-hant 5 · de·id·pt 각 3 …). 전건 원문 판정 후 ALLOW 등재.
- **G5** C2 19쌍 육안 대조. 가장 큰 계열 = **«실수 표»**(`ミス|なぜ損するか|直し方` 꼴)가 `holdem-3bet` ↔ `holdem-continuation-bet` ↔ `holdem-when-to-fold` 사이에서 짝지어진다 — **헤더가 같을 뿐 다른 표**다. 판정 후 등재해 닫는다.
