## 문체·표기
- **문체**: です/ます体 기본(정중체). 독자 지칭은 「あなた」. 카지노/포커 정보글 톤(친근하지만 정중).
- **숫자**: 아라비아 숫자. §13 값 그대로(천단위 콤마 `1,326`·`5,108`·`198,000`, 소수점 `.` — 영어식 유지). 산문에서 큰 수는 「3万ハンドに1回」처럼 万 단위 자연스럽게 허용(값 불변 범위). `%`는 반각(기존 하우스 스타일 `0.0032%`·`43.8%`).
- **통화**: `$` 유지(원문 그대로). 무리하게 円 변환 금지.
- **문장부호**: 전각 「」『』（）、。 사용. EN `——`는 전각 `——`(全角ダッシュ) 또는 「──」.
- **카드 표기**: A♠ K♥ 10♦ 등 **그대로**(RTL 아님, 반각 유지). 役の中の数字도 A/K/Q/J/10.

## ポーカーの役 (hand rankings) — 하우스 스타일 확정(기존 ja 글 기준)
| EN | ja(주표기) | 별칭/비고 |
|----|-----------|----------|
| Royal Flush | ロイヤルフラッシュ | — |
| Straight Flush | ストレートフラッシュ | 最弱 A-5=スチールホイール |
| Four of a Kind | フォーカード | クワッズ(併記可) |
| Full House | フルハウス | ボート(併記可) |
| Flush | フラッシュ | — |
| Straight | ストレート | ブロードウェイ(A-K-Q-J-10)·ホイール(A-2-3-4-5) |
| Three of a Kind | スリーカード | セット(ポケットペア+ボード)/トリップス(ボードペア+手札1枚) 구분 중요 |
| Two Pair | ツーペア | — |
| One Pair | ワンペア | — |
| High Card | ハイカード | ノーペア |

- **フラッシュ(#5) > ストレート(#6)** — 일본 사이트 공통. 이유=「揃えるのが難しい役ほど強い」(희소성).
- 役全般은 **カタカナ가 표준**(직역 한자役名 금지).

## 액션·핵심 용어 (일본 포커 씬 실사용 — 대부분 영어 음차 카타카나)
- ベット / レイズ / コール / チェック / フォールド / オールイン / ブラフ
- **キッカー**(kicker) — 직역. 「役に含まれないが同ランク対決で優劣を決める最後の1枚」. 適用役=ワンペア/ツーペア/スリーカード/フォーカード/ハイカード(ストレート·フラッシュ·フルハウス·SF엔 미적용).
- **チョップ**(chop) = 引き分け·分け合い. スプリット도 통용(併記 가능, 기존 글은 スプリット 사용). ポット分配.
  - **端数チップ**(odd chip) = 割り切れない端数 → ポジションの悪い側(SBが最悪)に配分.
  - ブラインドチョップ = プリフロップでブラインド同士の合意分け.
- サイドポット / メインポット (side pot / main pot)
- **コミュニティカード**(공유 5장) / ボード / **ボードテクスチャ** / **ナッツ**(그 보드 최강 핸드)
- フロップ / ターン / リバー / プリフロップ / ショーダウン
- ランク(数字의 강함) / スート(마크, 강약 없음)
- ペアボード(paired board) / 「ボードがペアになる」

## 판정 순서(タイブレーク) 관용 표현
- 同役対決: ①役の강함 → ②役を構成するカードの数字 → ③キッカー(上から1枚ずつ) → ④それでも同じなら引き分け(チョップ). スートで引き分けは決まらない.
- ワンペア判定順: ペアのランク → キッカー(最強) → キッカー(2번째) → キッカー(3번째).

## SEO(현지 검색 각도) — 실제 검색어
- seoTitle/desc는 직역 금지, 일본 검색자가 치는 표현으로. 예:
  - flush vs straight → 「フラッシュとストレート どっちが強い」
  - kicker → 「ポーカー キッカー とは / キッカー負け」
  - split/chop → 「ポーカー チョップ 引き分け / ポット 分け方」
  - reading board → 「ボードの読み方 / 場の読み方」
  - tiebreak → 「同じ役 勝敗 / キッカー 比較」
- tags도 위 검색어군으로 현지화(직역 나열 금지). desc ≤ 160자, seoTitle 현지 SERP 잘림 고려.

## 確率・オッズ (Odds & Math) 用語 — Wave 2 (현지 웹리서치: mpj-portal·ABEMA·poker101·zero-poker·pokeracademy 등)
- **ポットオッズ** (pot odds) — 「コールに必要な額に対して、勝ったときに返ってくるポットの倍率」. 比率表記 `2:1`·`4対1` 등 EN 원문 비율 그대로(§13).
- **アウツ**(outs, 複数) / アウト(単数) — 「役を完成させるために必要な残りのカード枚数」.
- **2倍4倍の法則**(rule of 2 and 4) — 「アウツ×2(1枚)·×4(2枚)でおおよその完成率」. 例: フラッシュドロー9アウツ → ターン約18%.
- **ドロー**/フラッシュドロー/ストレートドロー/**ガットショット**(inside straight draw, 4アウツ)/**オープンエンド**(両面, 8アウツ)/**バックドア**.
- **エクイティ**(equity) — 「その時点でポットを獲得する確率」. ポットエクイティ.
- **インプライドオッズ**(implied odds) — 「今は見えない、次以降のベットで見込める上乗せまで含めたオッズ」. リバース・インプライドオッズ도.
- **期待値 / EV**(expected value) — EV 표기 유지.
- **必要勝率**(= 100% ÷ ポットオッズ) / ブレイクイーブン.
- ★숫자·비율·확률은 §13 불변. `%`는 반각, 오즈 비율(예 `3:1`, `2.5:1`)은 EN 그대로. 큰 팟 금액은 영어식 콤마.

## 戦略 (Strategy) 用語 — Wave 3 (현지 웹리서치: ABEMA·mpj-portal·pokeracademy·zero-poker·raq-hiphop 등)
- **ポジション**(position). アクション順 = UTG(最不利) → MP/HJ → CO → **BTN**(ボタン/ディーラーボタン, 最有利) → SB → BB(時計回り). アーリー/ミドル/レイトポジション.
- **UTG**(アンダーザガン)·**CO**(カットオフ)·**BTN**(ボタン)·**HJ**(ハイジャック)·MP·SB·BB — 略称は英語慣용 그대로.
- **タイト**(신중히 좁힘)/**ルース**(넓고 적극적). 철칙「位置が悪いほどハンドを絞り、良いほど広げる」.
- **スターティングハンド**/**ハンドレンジ**(レンジ) — 참가할 핸드 범위. ハンドレンジ表.
- **リンプ**(リンプイン; 오픈레이즈 가능한 상황에서 BB에 콜만)/リンパー. **オープンレイズ**(オープン)/アイソレート.
- **3ベット**(스리벳; 오픈에 대한 재레이즈)/**3ベットライト**(레인지 확대)/4ベット/コールドコール.
- **Cベット / コンティニュエーションベット / CB**(프리플랍 마지막 레이저=アグレッサー가 플랍서 계속 베팅)/**アグレッサー**/ディレイCベット. 標準サイズ 33% 등 EN 값 유지.
- **フォールド判断**/降りどき/フォールドエクイティ. バリュー/バリューベット/ブラフ/セミブラフ/エクイティ実現.
- 문체·숫자: 기존과 동일(です/ます, 영어식 숫자, 반각%, `$`·`BB` 유지). 스택·사이즈는 BB(ビッグブラインド) 단위 표기 그대로.

## トーナメント (Tournament) 用語 — Wave 4 (현지 웹리서치: GGPoker·poker-hack·mpj-portal·zero-poker·日本カジノスクール 등)
- **トーナメント / MTT**(マルチテーブルトーナメント) vs **キャッシュゲーム**.
- **ICM**(独立チップモデル) — 「順位ごとの入賞確率から期待賞金額を算出」. **バブルファクター**(칩 손실이 획득보다 에쿼티를 더 잃는 지표).
- **バブル**(賞金圏内と圏外の境目; 예: 상위30입상, 잔여31명 상황). **インザマネー(ITM)**=입상권.
- **ショートスタック / ミドルスタック / ビッグスタック**. スタック=칩량(BB 단위).
- **バイイン**(参加費 = プライズプール 몫 + レイク/手数料). **プライズプール**(賞金 총액, 순위 배분). **ペイジャンプ**(입상 단계 상금 점프).
- **レイトレジ**(レイトレジスト; 지각 참가 접수)/**アンティ**(중반 이후 가속용 강제 베팅)/リバイ/アドオン/ブラインドレベル.
- **ライブイベント 4편(APT인천·코리아마라톤·WPT호주·EPT바르셀로나)**: ★**§14 사실 정확성** — 대회명·날짜·바이인·프라이즈·운영사·장소 등 **EN 마스터 값 그대로**(임의 변경·창작 금지). 통화·숫자 EN 표기 유지. 지역명·고유명사는 일본어 관용 표기(예: バルセロナ·インチョン/仁川·オーストラリア).
- 문체·숫자: 기존과 동일(です/ます, 영어식 숫자, 반각%, `$`·현지통화 EN대로).

## 用語集・スラング (Glossary) 用語 — Wave 5 (ja 마지막 필라. 현지 웹리서치: zero-poker·pkerclub·WPT JAPAN·casino-dealer 등)
- **ストラドル**(straddle) — BB 왼쪽 옆이 카드 배분 전 BB 2배 블라인드를 내고 액션을 마지막으로 가져오는 옵션. **ミシシッピストラドル**(임의 포지션 스트래들)도.
- **レーキ**(rake) — 하우스(운영)가 걷는 手数料/자릿세. **レーキバック**(리베이트)·キャップ(상한).
- **フィッシュ**(fish) — 미숙한/약한 플레이어. 일본어 관용 **「カモ」** 병용. 대의어 **シャーク**(サメ).
- **クーラー**(cooler) — 양쪽 다 강해 피할 수 없는 패배 상황. **ジャストクーラー**(위로 표현).
- **バッドビート**(bad beat) — 강한 핸드가 낮은 확률로 역전당하는 이불킥급 敗北. **バッドビートジャックポット**(특정 강패 패배 시 보너스)도.
- 문체·숫자: 기존과 동일(です/ます, 영어식 숫자, 반각%, `$`·`BB` 유지). 속어라도 억지 신조어 금지—일본 포커 씬 실제 통용 카타카나.

# 대회·여행 글 실전 교정 (apt-incheon 미러, 2026-07-28)

## ★1. 일본 독자에게 가장 잘 들키는 직역 — "시차"
- **일본과 한국은 시차가 없다(둘 다 UTC+9).** 영어 마스터의 jet lag 문구가 그대로 넘어오면
  일본 독자는 즉시 "이 글 일본용이 아니다"라고 판단한다.
- ❌ "時差ボケから回復し…" → ✅ "**日韓に時差はない**ので体は楽ですが、初日から会場の勝手が分かっていると
  登録・両替・席探しで消耗しません"
- ❌ "Day 1を自分の**ホームタイムゾーン**でプレー"(일본인에게 타임존은 이점이 아님)
  → ✅ "**日本にいながらDay 1を消化**"(진짜 이점은 **항공・宿泊費**)

## ★2. 円 환산은 필수
- 일본 독자는 **엔으로 예산을 짠다.** USD만 쓰면 판단이 안 된다.
- 최소 병기 대상: 메인이벤트 바이인 · 저가 사이드이벤트 · 시트 가치 · 예산표 합계
  (예: KRW 2,500,000 = 約$1,703 / **約26万円**, $10,000 시트 = **約155万円**)

## ★3. 선수명 한자 — 확인 안 되면 쓰지 말 것
- APT 공식 · PokerNews · SomuchPoker · poker.org **전부 로마자 표기만** 사용
- 일본어 검색으로도 **성(奥宮/黒田)까지만** 확인되고 이름 한자는 1차 출처 없음
  (다른 한자를 쓴 사이트도 존재 = 표기가 갈림)
- → **공식 로마자로 통일**하고 그 사실을 각주로 명시. 로마자 어순도 통일할 것
  (기존 원고는 「奥宮広樹(Kouki Okumiya)」=名→姓 / 「黒田清人(Kuroda Kiyoto)」=姓→名로 섞여 있었음)

## 7. 배치 원칙 — 「돈」이 「절차」보다 먼저다

ラッコ 실측: `参加費` 210 > `ルール` 110 > **`参加方法` 30**.

- H2 예: ❌ `Natural8で予選突破する方法` → ✅ `予選はいくらから狙えるのか?`

## 8. H2 형태소 — 「〜は?」 명사 종결이 지배형

질문 DB 213건에서 확인. `〜ですか?`는 **돈 관련(`いくらですか?`)에 몰린다.**

```
ポーカーの三大大会は?      日本で最大のポーカー大会は?
国内ポーカー大会の日程は?   2026年のポーカー大会の日程は?
```

→ ko의 「〜하나요?」를 「〜できますか?」로 옮기면 형태소가 어긋난다. **명사구로 끝낸다.**
「日本最大の〜」 계열이 4회 반복되므로, 자국 대회 글은 **규모 비교**를 답해야 한다.

## 9. ★ 대회장명을 제목·H2에 넣는다

`パラダイスシティ ポーカー 大会` **90/월**이 대회장명 단독으로 검색된다.
질문형으로도 `パラダイスシティポーカー大会の参加費はいくらですか?`가 잡힌다.

→ **대회 브랜드를 모르고 대회장명으로 찾는 독자가 있다.**
   APT 仁川·APPT 韓国 글은 제목에 `パラダイスシティ`를 넣는다.

## 10. ★ 「違法ですか?」 수요 처리 — 제도가 아니라 절차를 쓴다

질문 DB에서 위법 여부가 5회 이상 반복되고 `ポーカー 大会 賞金 違法`이 **170/월**이다.

「違法ですか」로 검색하는 독자가 실제로 알고 싶은 것은 **"내가 평범하게 참가해도 되는 일인가"**다.
