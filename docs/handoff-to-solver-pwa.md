# 솔버 세션 요청 — GTO 솔버를 PWA로 (2026-08-15 사장님 결정)

> 이 파일은 **본체 세션이 솔버 세션에 보내는 요청서**다.
> `클로드-프로그램만들기` 폴더는 읽기 전용이라 여기에 두고, 사장님이 전달한다.
> 솔버 세션 `작업계획.md`의 후보 「PWA(홈 화면 설치 + 오프라인 트레이너)」를 **채택**한다.

## 1. 왜 솔버인가 (본체가 아니라)

사장님이 세운 그림이 맞고, 본체 실측이 그걸 지지한다.

> 「유저가 PWA로 홈 화면에 설치하면 필요할 때마다 쓸 수 있고, 나는 SEO로 유입이 많이 되니 좋다.
>  솔버를 PWA 하면 **해설보기 링크 타고 홀덤마스터로 유입**된다」

- **순환이 이미 만들어져 있다.** 트레이너가 채점한 뒤 「이 스팟 해설 읽기」로 본체 13편에
  UTM 링크를 건다(`utm_content=trainer-feedback`). PWA는 그 순환의 **입구를 홈 화면에 박는 일**이다.
- **솔버는 «열어서 쓰는 도구»다.** 무료 + 반복 학습 + 오프라인 가치(교육 예제 13개가 미리 계산돼 있음)
  → 설치 동기가 실재한다.
- **본체는 반대다.** 유입의 77%가 검색이고, 검색으로 와서 답을 얻으면 떠나는 게 정상 패턴이다.
  아이콘을 만들어도 누를 이유가 약하다. 게다가 본체는 **SSG 630페이지 + 매일 크론 재빌드**라
  서비스워커 캐시가 낡은 HTML을 붙들면 「어제 고친 게 오늘 안 보이는」 사고가 난다.
  솔버는 SPA 단일 번들이라 그 위험이 낮다 — **「위험 0」은 솔버에서만 참이다.**

### 본체 실측 (2026-08-15 · GA4 28일)

| 지표 | 값 |
|---|---:|
| 활성 사용자 | 2,113 (신규 1,906 · **재방문 207 = 9.8%**) |
| 평균 세션 | 신규 167초 · **재방문 385초 (2.3배)** |
| DAU / WAU / MAU | 124 / 668 / 2,100 → **DAU/MAU 5.9%** |
| 기기 | 모바일 1,165(60%) · 데스크톱 752 |
| 채널 | Organic Search 77% · Direct 22% |

★ **재방문자는 이미 2.3배 깊게 본다.** 문제는 깊이가 아니라 **돌아오는 수**다.
→ 홈 화면 아이콘이 그 «돌아오는 경로»를 만든다.

⚠ **GA4 벤치마크(「포커 및 카지노 게임」) 상위 25%를 목표로 삼지 말 것.** 그 집단은 게임 앱이
주력이라 DAU가 구조적으로 높다. 우리 곡선은 동종 **중앙값에 이미 근접**해 있다.
볼 지표는 순위가 아니라 **DAU/MAU가 오르는가**다.

## 2. 요청 범위

1. **Web App Manifest** — 이름·아이콘·`display: standalone`·`theme_color`·`start_url`
   - 아이콘은 홀덤마스터 스페이드 로고 계열로 (본체 파비콘과 톤 통일)
   - `start_url`은 **교육 예제 또는 트레이너**를 권한다 — 설치한 사람은 이미 «쓰러 온» 사람이라
     소개 화면을 다시 보여줄 이유가 없다
2. **Service Worker** — 앱 셸 + **교육 예제 13종 미리 계산 데이터** 캐시
   - 솔버 세션 기록에 「트레이너 데이터 1.6MB라 통째 저장 가능」이 있다 → **지하철에서 공부**가 실질 무기
   - 🔴 **캐시 무효화 전략을 반드시 명시할 것.** 배포마다 번들 해시가 바뀌므로
     stale 셸이 남으면 «업데이트가 안 되는 앱»이 된다
3. **설치 유도(A2HS) 배너** — 남용 금지. 권하는 자리 둘:
   - 교육 예제를 **2개 이상 연 뒤**
   - 트레이너에서 **문제를 몇 개 푼 뒤**
   (첫 진입에 띄우면 거절률만 올린다)

## 3. 알아둘 제약 (솔버 세션이 이미 정리한 것 + 본체 확인분)

- 🔴 **iOS**: 사파리는 단일 스레드라 직접 계산이 느리다 → iOS 사용자에게는
  **교육 예제·트레이너 중심**으로 안내하는 편이 낫다(이미 앱 FAQ가 그렇게 적고 있다).
  웹 푸시도 iOS는 **「홈 화면에 추가」한 경우에만** 동작한다(16.4+).
- 🔴 **앱스토어는 권하지 않는다** — AGPL이 애플 약관과 충돌(VLC 선례). 솔버 세션 판단 그대로 유지.
- 🪶 **푸시는 이번 범위에서 뺀다.** 통로보다 **보낼 내용**이 먼저다.
  지금 정기 소재는 본체의 「매주 일요일 19시 이벤트 추첨」 하나뿐이고, 그건 본체 소관이다.
  → 「오늘의 문제」(솔버 세션 후보)가 생기면 그때 푸시를 논한다.

## 4. 본체가 이어서 할 일 (솔버 PWA 배포 후)

- `/solver` 랜딩에 **설치 안내 한 줄** 추가 — 이 랜딩은 **네이버 웹사이트 영역 1~3위**로
  이 축의 유입을 사실상 혼자 받고 있다(「홀덤 gto 표」 1위 · 「홀덤 gto 프로그램」 2위).
  설치 동선을 여기 두는 것이 가장 값싸다.
- 랜딩 FAQ에 「홈 화면에 설치할 수 있나요?」 문항 추가 (14 → 15문항)
- ⚠ **솔버가 실제로 PWA가 된 뒤에 쓴다.** 안 되는 기능을 먼저 적지 않는다
  (이 레포의 규율 — 라이브 확인 후 서술).

## 5. 성과 판정

- 기준선(2026-08-15): **DAU/MAU 5.9% · 재방문 9.8% · 재방문 세션 385초**
- 4주 뒤 재측정. 🔴 **PWA 단독 효과는 분리해서 못 잰다** — 같은 기간에 네이버 색인·제목 재조준이
  함께 돌아간다. 그러니 «PWA가 몇 % 올렸나»를 묻지 말고 **DAU/MAU 방향만** 본다.
