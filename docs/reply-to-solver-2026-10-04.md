## 배경 한 줄
솔버(noindex)는 사용량이 본체 검색 노출로 안 이어진다 → 후기를 **색인되는 본체 랜딩 `/{locale}/solver`**에 쌓는다. 받는 곳 = 앱 안(쓴 직후) · 보이는 곳 = 그 언어 랜딩. **전 언어(12) 동시 개통.** 후기는 **쓰면 바로 공개**(숨김 = 링크·욕설·광고만, 사후) · **누구나**(사용 횟수 문턱 없음) · **이벤트와 별개**(후기창에 보상·응모·꼬리표 없음).

## 요청 ① 앱 안 후기 자리 + 폼

**자리(설계 §2-2)**

| 자리 | 언제 | 모양 |
|---|---|---|
| 앱 메뉴 | 항상 | «후기 남기기» |
| 결과 화면 아래 | 항상 | 작은 글씨 한 줄 «써 보니 어땠나요?» |
| 결과 화면 아래 (1회) | 기기에서 **3번째 솔브 완료** 직후 그 결과 화면에서만 | 고정 줄과 별도의 한 줄 · **닫기 버튼 없음** · 다음 결과부터 안 나온다 · 팝업 아님 |

- 자리 문구는 늘 중립 고정(보상 문구 금지).

**폼(설계 §2-1 — 폰 한 화면 · 앱 안에서 연다, 본체로 이동시키지 않는다)**
- 별점 탭 1~5(선택 · 44px 이상 · 다시 누르면 해제) · 본문 **2~600자**(필수) · «아쉬운 점» 0~200자(선택 · 접힘)
- 별점만 있고 본문이 비면 «한마디만 남겨 주세요» 안내(글 없는 별점은 받지 않는다)
- 본문에 링크가 보이면 입력 중 «링크는 넣을 수 없어요»(본체 규칙 = `lib/participation-config.ts` `LINK_PATTERN` — 정규식 축어를 같이 쓰면 된다 · 최종 검사는 본체 서버)
- **로그인은 [남기기]를 누를 때만** — 안 돼 있으면 구글·카카오(카카오 ko만) → 돌아오면 **쓴 글 그대로 자동 전송**(초안은 기기 임시 보관)
- 첫 후기면 «○○ 으로 남깁니다 [바꾸기]»(닉네임 = `profiles.nickname` · 바꾸기는 본체 API로 — ② 아래 명세에 포함 예정)
- 전송 = 본체 **`POST https://www.holdemmaster.com/api/solver-feedback`** · `Authorization: Bearer <Supabase access token>` · 본문 `{ locale, kind: "review", body, downside?, rating?, device }` (device = phone/tablet/desktop 세 값 · 모델명 금지). 응답의 오류 코드별 문구는 본체가 12언어 사전으로 같이 넘긴다.
- 1인 1언어 1후기 — 이미 썼으면 폼이 «수정»으로 열린다(본체 API가 기존 후기를 돌려준다).
- 🔴 **앱이 Supabase에 후기를 직접 쓰지 않는다**(검사를 본체 TS 한 벌로 — RPC 안 기각).
- 12언어 문구 초안은 본체가 사실 시트 §5로 검수해 넘긴다. placeholder에 솔버 수치·비교·기능 약속 금지.

## 요청 ② 공유 링크 본체 경유

- 앱 «공유»가 본체 **`POST /api/spot-share`**에 지금의 `?spot=` 값(상한 16384자 · `spot-share.ts:127`과 같게)을 보내고 `https://www.holdemmaster.com/s/<id>`를 받아 그 주소를 복사·공유한다.
- 본체 `/s/<id>` = 보드·자리·팟 미리보기 + «솔버에서 열기»(원래 `?spot=` URL로 이동) · **noindex**.
- 미리보기 정보(보드·자리·팟)는 **본체 서버가 payload를 디코드해 직접 만든다**(클라이언트가 보낸 meta는 받지 않는다). → 솔버 `spot-share.ts`의 디코드·검증 로직(`fromBase64Url` · `validSharedLines` 등)을 본체로 옮겨 심을 수 있게 **함수 목록과 형식 버전(v1·v2·v3) 정의 위치**를 알려 달라.
- 본체 저장이 실패하면 기존 `?spot=` 링크로 폴백(공유가 막히지 않게).
- 로그인 불필요 · 본체가 IP 해시 속도 제한.

## 요청 ③ PWA 설치 자리에 요약 한 줄

- 본체 `GET /api/solver-reviews/summary?locale=xx` → `{ text: "후기 N · ★ 4.6 (별점 R개)" | "" }`(그 언어 문자열로 완성해서 준다). 빈 문자열이면 줄을 숨긴다(후기 3개 미만).
- 숫자만 — 후기 문장 인용 없음(후기 속 «○○만큼 좋다»를 우리 문구로 재사용하면 비교 광고가 된다 · 사실 시트 §5).

## 통지 1 — `trainer_attempts.created_at` 강제 트리거 (솔버 동작 영향 없음 예상)

본체 코드 1 SQL에 `trainer_attempts` before insert 트리거로 **`created_at := now()`**를 넣는다(지금은 `default now()`뿐이라 insert 때 값을 넣으면 덮어쓴다). 후기 옆 «솔버 사용 기록 있음» 표시(문턱 아님 · 덧붙는 표시)의 날짜 근거로 쓴다. 앱이 `created_at`을 직접 넣는 곳이 있으면 알려 달라 — 없으면 트레이너 동작에 변화 없음(앱은 `played_at`을 쓴다).
