## 0. ★★ 한 장 요약 (가장 중요)
1. **기술 포커 용어는 전 스페인어권 거의 동일**(farol·all-in·cooler·bad beat·tilt·pescado·fichas·color=flush·escalera). → **개념/용어 쿼리 SEO는 지역차가 없고 Spain .es가 장악**. 여기서 이기려 하지 말 것.
2. **지역차는 4개 층에만 있다:**
   - **① 문법 register**: voseo(아르헨·우루과이) vs **tú**(그 외 전부) — **하드 포크**(본문 레벨, 키워드 아님)
   - **② 슬랭/색채**(돈·감정·호칭·플레이어類) — 얇지만 real. 안데스는 **없음**(neutral)
   - **③ 통화**: 나라마다 다름(아래 표)
   - **④ 합법성/시장**: ★**최대 차별화 + 최대 winnable 레인**
3. **winnable = 개념글(Spain 소유) 아님. 로컬**: 합법성·통화·도시별 살라/대회·"qué es [영어term]"를 현지 register로.
4. **공통 base voice = neutral LATAM + 영어 loanword(남성관사: el flop/turn/river/pozo)** — VE 디아스포라 온라인 그라인더 톤 = "español neutro"(멕시코 앵커, 슬랭 제거)가 가장 넓게 통함. 계파 슬랭은 FAQ/flavor로만.

## 3. ★ voseo (아르헨·우루과이) — 유일한 문법 하드포크
- **본문엔 voseo, 키워드엔 부정사.** 아르헨도 검색은 "como jugar al poker"(부정사)로 침 → voseo는 **답(본문·CTA·명령형)을 현지처럼** 만드는 것.
- 명령형이 최대 레버리지: **jugá·apostá·subí·retirate·concentrate·definí·fijate**, 부정=no apostés·no te vayás en tilt. tenés·podés·jugás·querés.
- 멕시코(tú: apuestas·tienes·puedes)와 **정반대**. AR+UY 한 세트로 커버(통화·결제레일·합법성만 분기).

## 4. 검색 방식 (전 계파 공통 + 특이)
- **철자**: 무악센트 **poker**가 쿼리 지배(슬러그·H2는 poker) / **póker**는 본문 polish / **póquer=스페인 격식 tell**(LATAM엔 안 씀) / poquer=얇은 음성 롱테일.
- **프레임**: **영어term+"que es" 후치**("bad beat poker que es") · ¿qué es? · cómo se juega · cuál es la peor mano · **qué gana/vale más X o Y**(고의도 비교).
- 영어 jargon은 영어로 검색+스페인어 설명 읽음. 정착 스페인어(farol·burbuja·color·escalera·tiburón·pez)만 스페인어 검색.
- ★**지오 커머셜 롱테일**="desde [país]"·"[concepto] [país]"·"casino/salas [ciudad]"·"[país] es legal" = winnable.
