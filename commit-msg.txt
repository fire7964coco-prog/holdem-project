fix(audit): --slug 모드에서 죽어 있던 형제 표 교차대조(C1/C2)·필라 역링크(F12) 복구

핸드오프에 "C1이 계속 0쌍 = 헤더 매칭 실패"로 기록돼 있었으나 오진이었다.
전체 실행에서는 25쌍이 정상 대조되고 있었고, 실제 원인은 --slug 모드가
대상 1편만 로드해 형제 대조를 시도조차 안 한 것이다. 경화는 언제나
--slug 1편 단위로 돌리므로, 정작 쓰는 순간에만 검사가 죽어 있었다.

- clusterOf(slug) 역인덱스 추가 → --slug이 소속 클러스터 형제 전원을 끌어온다
- auditClusterTables(focus) → 내 글이 낀 쌍만 보고(형제끼리의 지적으로 오염 방지)
- F12(필라 역링크)도 같은 구멍이었다 → slug 역인덱스로 1편 모드에서 복구
- "0쌍" 원인을 구분해 출력: 형제 없음 / 표 없음 / 진짜 매칭 실패
  (게이트가 침묵의 이유를 틀리게 말하면 사람이 엉뚱한 데를 고친다)
- 대조 못 한 행 수를 항상 표시 — 0건이 미검사 공백을 덮지 않게

검증: selftest 50 → 56/56 (focus 필터 3 + 역인덱스 3 픽스처 추가)
      족보 필라 --slug: 0쌍 → 4쌍·23행 / 기본 모드 회귀 없음(25쌍·108행 동일)
      --all에서 F12 신규 오탐 0건
