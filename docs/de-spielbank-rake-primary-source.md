## 2. 🔴 여기서 나오는 사실들 — 글을 고칠 때 이걸 쓴다

### ① **캡은 €10(1/1·1/2) → €20(2/2 이상)** 이다

검수장이 지시서에 적은 「Spielbank 공식 캡 1/1 €10 · 2/2 이상 €20」이 **원문으로 재확인됐다.**
종전 본문의 `$3–$6` 대비 **2~5배**다.

### ② 🔴 **구조가 «퍼센트»가 아니라 «구간별 고정액»이다**

이것이 캡 숫자보다 중요하다. 「10% des Pots gecappt bei $5」 같은 미국식 서술을
**금액만 바꿔 옮기면 여전히 틀린다.** 독일 슈필방크는 팟 구간마다 €가 정해져 있다.

실효 요율 검산(Blinds 1/1):

| 팟 | 레이크 | 실효 요율 |
|---|---|---|
| €10 | €1 | **10,0%** |
| €19 | €1 | 5,3% |
| €20 | €2 | 10,0% |
| €59 | €2 | 3,4% |
| €60 | €4 | 6,7% |
| €99 | €4 | 4,0% |
| €150 | €10 (캡) | 6,7% |
| €300 | €10 (캡) | 3,3% |

→ 🟢 **글의 「Rake-Falle」 주장은 살아남고, 오히려 독일 표가 더 좋은 근거다.**
   구간 하단(€10 → €1, €20 → €2)에서 **정확히 10%**를 떼고, 팟이 커질수록 비율이 떨어진다.

### ③ 🔴 **「대부분의 경합 팟이 캡에 닿는다」는 독일에선 거짓이다**

Blinds 1/1 에서 캡은 **팟 €150** 부터다. €1/€1 게임에서 €150 팟은 드물다.
2/2 는 **€400** 부터다. 미국식(10% capped $5 → $50 팟이면 캡)과 완전히 다르다.
**금액만 바꾸고 이 문장을 남기면 새 사실오류가 생긴다.**

### ④ 🟢 **`NO FLOP - NO DROP` 이 공식 표에 축어로 있다**

글의 기존 서술(「Die meisten Räume nehmen nichts, wenn vor dem Flop alle folden」)이
**독일 1차 출처로 뒷받침된다.** 종전에는 근거가 일반론뿐이었다.

### ⑤ 🆕 **`SPLIT POT - NO DROP`** — 글에 없던 사실

스플릿 팟에서도 드롭하지 않는다. 같은 표 머리에 축어로 있다.
