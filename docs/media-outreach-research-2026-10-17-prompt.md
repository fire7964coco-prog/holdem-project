# 조사 의뢰 — «무료 GTO 솔버» 유료 기사·리뷰 게재: 어느 매체·업체에 맡기는 게 가장 효율적인가 (2026-10-17)

## 핵심 질문 (이것 하나에 답하라)
**같은 돈으로 가장 큰 효과를 내는 유료 게재처는 어디인가?** 후보를 실제로 찾아 비용·효과 지표를 원문으로 모으고, 효율 순으로 비교표를 만든다.

## 무엇을 알리는가 (프레이밍 — 반드시 이 틀로)
- 알릴 대상 = **무료 웹 GTO 솔버**(solver.holdemmaster.com). 게임이론으로 포커 상황의 최적 전략을 계산해 보여 주는 **전략 분석·학습 소프트웨어**다. 돈을 거는 기능 없음 — 체스 엔진·계산기와 같은 부류.
- 🔴 **카지노·도박·베팅 광고 상품·카지노 제휴(affiliate) 쪽은 조사 대상이 아니다.** 그쪽은 비싸고 구글 페널티 위험이 크다. 검색어도 그 틀로 잡지 마라. 매체 분류는 «포커 전략·교육», «테크·IT·스타트업», «에듀테크», «게임/마인드스포츠», «보도자료 배포»로.
- 도구 사실 정본 = 이 폴더 `solver-factsheet.md`. 거기 없는 기능을 전제하지 마라.
- 운영 사이트 holdemmaster.com = 한국어 메인 + 다국어(영어·일본어 등) 포커 전략 블로그.
- 목적 = ① 백링크 ② 도메인 권위 ③ 회원 유입(솔버 사용자). 우선 시장 = 한국·영어권·일본(다른 곳에 강한 후보가 있으면 추가).

## 후보 유형 (넓게 찾되 «유료로 살 수 있는 것» 중심)
1. **포커 전략·뉴스 전문 매체**의 스폰서 기사·리뷰·광고 상품 (독자가 곧 솔버 사용자)
2. **테크·IT·스타트업·에듀테크 매체**의 유료 소개 기사·신제품 기사 (한국 인터넷신문의 «기사형 광고·기자 연결» 상품 포함)
3. **보도자료 배포 서비스** (한국·영어권·일본 — 패키지별 가격·배포처 수·Google 뉴스 노출 여부)
4. **게스트 포스트·링크 마켓플레이스·중개사**(FatJoe·Accessily 같은 곳) — 실제 어떤 매체에 실리는지, 포커 전략 주제 게재 가능 매체가 있는지
5. **포커 유튜버·스트리머·뉴스레터 유료 리뷰/스폰서** (단가 공개된 것)
6. 비교 기준선으로만: 무료로 될 수 있는 경로(제보 창구·디렉토리·커뮤니티)는 짧게.

## 각 후보에서 모을 «효율 지표» (원문 있는 것만)
- 비용(상품·패키지별 · 통화 · 출처 URL)
- 매체 규모: 월 방문·구독자·조회수 — 매체 자체 미디어킷·광고 페이지 수치 우선(타사 추정치는 «2차» 표시)
- 독자 적합도: 포커 전략 독자인가 / 일반 테크 독자인가 / 언어·국가
- 링크: dofollow·nofollow·sponsored 표기 여부(원문), 영구 게재인지 기간제인지
- 기사가 Google 검색·Google 뉴스에 색인되는지(원문 근거 있을 때만)
- 포커 전략 주제 게재 제한 문장이 원문에 있으면 축어로
- 실제로 비슷한 도구(포커 트레이너·솔버·계산기·학습 앱)가 그 매체에 실린 사례 URL

## 서치 규율 (반드시)
1. 검색 요약을 사실로 쓰지 마라. **원문 페이지를 직접 열고 축어 인용** + URL + 열람일.
2. 가격·정책은 **공식 페이지 원문**에서만. 리셀러·블로그 수치는 «2차»로 따로.
3. 못 열었거나 원문에 없으면 «미확인». 빈칸을 추측으로 채우지 마라. **오탐이 미탐보다 나쁘다.**
4. 매체 이름을 기억으로 나열하지 마라 — 열어서 확인한 것만 표에.

## 산출 형식 (한국어, 마크다운)
1. **결론 한 쪽**: 목적(백링크 / 권위 / 유입)별로 «효율이 가장 좋아 보이는 후보 상위 3~5»와 근거 — 비용 대비 무엇을 얻는지. 근거가 원문인지 2차인지 표시.
2. **비교표**: 후보 | 유형 | 시장·언어 | 상품·가격(출처) | 매체 규모(출처) | 독자 적합도 | 링크 속성 | 색인 | 사례 | 1차/2차.
3. **구글 정책 축어**: 유료 링크·보도자료 링크·스폰서 기사에 대한 Google 검색 센터 원문 문장(링크 스팸 · rel="sponsored") — 비교표의 링크 효과를 해석할 때 쓸 기준.
4. **함정**: 중개사 품질 문제(PBN·링크팜 의심 신호 등), 원문으로 확인된 것만.
5. **미확인·못 연 것**.
6. **사장님이 정할 갈림길** 3~5개(예산 범위·시장 우선순위 등).
