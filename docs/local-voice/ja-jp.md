## 0. ★★ 한 장 요약 (여기만 읽어도 톤은 잡힌다)

1. **앵커는 「大会」다.** 「トーナメント」가 아니다. `ポーカー 大会` 2,900/월.
2. **질문 형태는 「〜は?」**(명사 종결). `〜ですか?`는 돈 관련(`いくらですか?`)에 몰린다.
   ko의 「〜할 수 있나요?」를 그대로 옮기면 형태소가 어긋난다.
3. **돈이 1순위 관심사다.** `参加費`(210) · `賞金`(320)이 `ルール`(110)·`参加方法`(30)보다 크다.
   → 비용 표를 위로 올린다. 절차 설명은 그 다음.
4. **국내 도시 수요가 실재한다.** 大阪 210 > 東京 140 > 名古屋 70 = 福岡 70 > 札幌 30.
   자국 대회 글을 쓸 때 **도시명이 승부처**다.
5. **한국·대만은 이미 검색되고 있다.** `パラダイスシティ ポーカー 大会` 90 ·
   `台湾 ポーカー 大会 2026` 70 · `ポーカー 大会 韓国` 50. 우리 데이터가 가장 두꺼운 곳과 겹친다.
6. **연예인/유튜버가 진입 경로다.** 田中圭(720/월) · ヨコサワ · 和田まんじゅう.
   일반 일본인은 「포커 대회」를 이 경로로 처음 안다. 인용은 하지 않아도 **인지 수준을 이 선에 맞춘다.**
7. **★「違法ですか?」 수요가 크지만 우리는 다루지 않는다.** 처리법은 §6.

## 2. 질문 형태 (Q-A-E H2 설계용, rakko 実測 213건 중)

### 2-1. 지배 형태 = 「〜は?」 (명사 종결)

```
ポーカーの三大大会は?
日本で最大のポーカー大会は?
国内ポーカー大会の日程は?
日本のポーカー大会の一覧は?
2026年のポーカー大会の日程は?
aptポーカー大会とは?
```

→ H2를 `〜は?`로 끝내는 명사구로. **ko의 「〜하나요?」를 「〜できますか?」로 옮기면 형태소가 어긋난다.**

### 2-2. 돈은 「いくらですか?」

```
ポーカーの世界大会の賞金はいくらですか?
韓国ポーカー大会の参加費はいくらですか?
パラダイスシティポーカー大会の参加費はいくらですか?   ← 회장명 + 참가비
名古屋ポーカー大会の賞金はいくらですか?
```

### 2-3. 「日本最大」 계열이 반복된다 (강한 의도)

```
日本で最大のポーカー大会は?
日本で1番大きいポーカー大会は?
ポーカーの日本最大大会は?
ポーカーで日本一の大会は?
```

→ 자국 대회 글에서 **규모 비교**를 요구한다. "JOPT는 국내에서 어느 위치인가"를 답해야 한다.

### 2-4. 대만·아시아도 질문형으로 잡힌다

```
台湾で2026年に開催されるポーカーの大会ではどんな大会がありますか?
アジアポーカー大会2025のスケジュールは?
韓国ポーカー大会2024のスケジュールは?
```

## 4. 문체 레지스터

- **기본 = です・ます체.** 포커 전문 매체(PokerNews 일본어판 등)도 이 선이다.
- **1인칭은 최소화.** 「私は」를 반복하지 않는다. 경험담은
  「現地で並んでいると気づくのですが」처럼 **관찰 서술**로 넣는다.
- **단정 회피 표현을 남용하지 않는다.** 「〜かもしれません」을 문단마다 쓰면 신뢰가 떨어진다.
  확인된 사실은 **단정형**으로. 미확인은 아예 쓰지 않는다(§13).
- **숫자 앞에 감탄을 붙이지 않는다.** 「驚きの$1,000,000!」 X → 「バイインは$1,000。そこから$1,000,000です」 O
- **다시(ダッシュ) `——` 를 논지 전환에 쓴다.** 일본어 웹 기사에서 자연스럽다.
- **강조는 `==**...**==`** (사이트 컨벤션). 문단마다 남용하지 않는다.

## 6. ★ 「違法ですか?」 수요 처리 방침 (중요)

rakko 질문 213건 중 **위법 여부 질문이 5건 이상 반복**된다.

```
日本でポーカー大会は違法ですか?
ポーカーの日本大会は違法ですか?
ポーカー大会は日本では違法ですか?
ポーカー大会は違法ですか?
```

키워드로도 `ポーカー 大会 賞金 違法` **170/월**이다. 수요는 명백히 크다.

### 그런데 우리는 이 축으로 쓰지 않는다 (2026-07-29 확정 방침)

**위법/합법 프레이밍 자체를 하지 않는다.** 부정형 결론으로 글을 닫지 않는다.

### 그럼 독자의 실제 질문에 어떻게 답하나

「違法ですか」라고 검색하는 독자가 진짜 알고 싶은 것은
**"내가 평범하게 참가해도 되는 일인가"**다. 해외 대회 글에서는 이걸 **긍정형 실무 정보로** 답한다.

| ❌ 쓰지 않을 프레임 | ✅ 쓸 프레임 |
|---|---|
| "일본에서는 〜가 위법이라" | (언급 자체를 하지 않음) |
| "그러나 해외라면 문제없습니다" | 「パラダイスシティは仁川空港から無料シャトルで10分。パスポートを見せて入場します」 |
| 제도 논의 | **입장 절차 · 필요 서류 · 연령 조건 · 예산**을 사실로 기술 |

즉 **제도가 아니라 절차를 쓴다.** 독자는 "무엇을 들고 가서 무엇을 하면 되는가"를 알면 질문이 해소된다.

## 7. 통화·숫자 감각

- **円 환산은 기준점만.** 고정 환산율을 본문에 박지 않는다(환율이 움직이면 거짓이 된다).
  기존 글의 방식: 「$10,000(1ドル155円換算で約155万円)」 — **환산율을 명시**해서 시점을 드러낸다.
- **일본어 숫자 포맷은 영어와 같다.** 천 단위 쉼표, 소수점 마침표. `$85,634,400` 그대로.
- **큰 금액은 億/万으로.** `15億ウォン` `180万ウォン` `¥15,000,000`.
  ko의 `15억`을 `1.5bn`으로 쓰지 않는다(그건 en).
- **원화는 「ウォン」.** `KRW 2,500,000`보다 `250万ウォン`이 읽힌다. 단 공식 표기 인용 시는 원문 유지.
- **체감 기준**: 일본 독자에게 `メインイベント 250万ウォン`은 감이 안 온다 →
  「約$1,700」 또는 「約26万円(1ウォン=0.105円換算)」처럼 **한 단계 더** 붙인다.

- **H2가 ko와 15개 대 15개로 동일** = 구조 미러링. 독자의 질문 순서가 우연히 같을 수 없다.
- `在外韓国人(海外の永住者)は、韓国パスポート+グリーンカード…` — **일본 독자에게 무의미한 문단**이
  자리를 차지하고, 그 자리에 들어가야 할 `羽田발 직항`이 없었다.
  → ko를 열어도 **구조는 보지 않는다.** 사실 확인용으로만.
- 일본 고유 정보가 `一時所得` 2회뿐이었다. 成田/羽田 직항·소요시간·일본 카드 결제가 전무.
