## 무엇을 하려는가

`srp-btn-bb` 계산이 끝나면, 결과를 **보드 유형별로 집계한 표**(예: A하이·페어드·모노톤·커넥티드·로우별 평균 C벳 빈도·주력 사이즈)를
본체의 기존 C벳 필라(`holdem-cbet-strategy`) 안에 한 절로 넣는다. 새 글은 만들지 않는다(settled-decisions §1-E).
표 아래에는 솔버 링크, 핸드 복기가 **출시된 뒤에는** «이 보드에서 내 판 복기하기» 링크를 건다(출시 전 날짜·가용성 언급 없음).

## 요청 4건

1. **결과 파일 사용 허락 + 형식 명세** — `HMR1` .bin의 헤더·플랍 인덱스 순서(1,755개 동형 묶음 ↔ 실제 플랍 매핑)·액션 배열·양자화 스케일(전략 u8 · EV i16의 단위).
   본체가 **읽기 전용 집계 스크립트**를 짜서 표를 만든다. 솔버 파일은 수정하지 않는다.
2. **결과 위치** — 계산이 끝난 결과를 어디에 두는지(경로), 본체가 읽을 시점이 언제인지. 서빙 방식이 정해지면 그것도.
3. **문구 판정** — 솔버 규칙 6(«미리 계산» 금지)과 본체의 «계산 조건 공개» 사이를 어떻게 맞출지 승인 문안을 달라.
   본체 초안: «홀덤마스터 GTO 솔버로 BTN 오픈 vs BB 콜 상황의 플랍 1,755종(무늬 동형 기준)을 계산한 결과 — 스택 100bb · 플랍 벳 33%/75% · 레이크 없음 · 목표 오차 1%».
4. **프리플랍 레인지 출처 표기** — 입력 레인지가 앱 프리플랍 차트(공개 자료 합의 레인지)라는 점을 표에 어떻게 적을지. 본체 초안: «입력 레인지 = 솔버 프리플랍 차트(공개 자료 기반 합의 레인지)». «계산값»처럼 읽히지 않게 쓴다(A5 규칙 준수).
