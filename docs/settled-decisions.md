### 3-E. 🔴 파일을 고칠 때는 «인코딩 먼저 → 임시 파일 → 교체» (2026-09-04 · 세 번째 재발 뒤 승격)

CLAUDE.md 세션시작 §2가 «문서가 통째로 비워지는 사고»를 경고하고 있다. **2026-09-04에 세 번째가 났고, 이번은 편집기가 아니라 우리 스크립트였다.**
```python
io.open(path, "w", encoding="utf-8")   # ← 열자마자 truncate 한다
... .write(text)                       # ← 여기서 인코딩이 터지면 원본은 이미 0바이트
```
`lib/tournaments.ts` 128,760바이트 → **0**. 원인은 문자열 리터럴의 `\ud83d\udd34`(🔴을 서로게이트 쌍으로 적음)이어서
UTF-8 인코딩이 불가능했던 것이다. 커밋 전이라 `git checkout --`로 복구하고 전 편집을 재적용했다.

🔴 **그래서 이게 정본이다:**
```python
def safe_write(path, text):
    data = text.encode("utf-8")   # ① 먼저 인코딩 — 실패해도 원본은 무사하다
    tmp = path + ".tmp"
    open(tmp, "wb").write(data)   # ② 임시 파일에 쓴다
    os.replace(tmp, path)         # ③ 원자적 교체
```

- 이모지는 **`🔴`** 형으로 적는다. 서로게이트 쌍(`\ud83d\udd34`)은 파이썬에서 **인코딩 불가 문자열**이 된다.
- 같은 계열 함정 = [[backticks-break-shell-strings]] — 셀 큰따옴표 안의 마크다운 백틱. **둘 다 «성공»으로 끝나고 조용히 깨진다.**
- 편집 직후 **`git diff --stat`과 파일 크기를 본다.** 증가만 했는데 줄어들었으면 멈춰라.

#### 🆕 5-A-3. 🔴 **2플랜 병렬 국면 — 본체 = Fable · 렌즈 = Opus · 전문 검수 = GPT(Codex)** (2026-09-04 사장님 지시)

#### 🆕 5-A-4. 🔴 회차 «모양» — 층을 정해도 «어디서 끊나»가 남는다 (2026-09-05 사장님 문답)

> 위 표는 **누가 무슨 층**인지만 정한다. 실제로 다음 세션이 막히는 자리는 «그래서 한 세션에

**경계선 한 줄 — 🔴 도구를 왕복하기 시작하면 Fable 구간이 끝난 것이다.**
근거는 위 ② 축이다. Fable은 **매 턴 전체 컨텍스트를 다시 읽으므로 턴 수가 곧 비용**이다.
저작은 «턴 적고 출력 김» = 유리하고, 실측·게이트는 «턴 많고 출력 짧음»(도구 왕복) = 최악이다.
→ **Fable 세션의 입력은 파일 하나(브리프), 출력은 파일 몇 개.** 그 앞뒤는 Opus.

**표준형 = 5세션** (GTO 13편 전파 기준 · 로케일 하나당)

    `build:vercel` 양쪽에 있다. **판정 대상이 «산출물의 공백»이 아니라 «소스의 개행»**이라
    한 줄 안의 의도적 공백(ja 태그 «韓国 ポーカー 税金»)은 원리상 후보가 아니다. 셀프테스트 12/12.
- 🔴 **`title: { absolute: … }`를 쓸 때는 `LocaleHomeJsonLd`를 함께 봐라** — `metadata.title as string`
  캐스팅은 객체를 JSON-LD에 넣는다. `const PAGE_TITLE`로 빼서 양쪽이 같은 문자열을 쓰게 한다.
- **DOM 밖 문자열(manifest·twitter 메타·스킵링크)은 언어 검사가 통째로 지나간다** — 새 로케일 화면을
  열면 DOM 밖 문자열도 함께 점검. **주석이 있어도 강제하는 검사가 없으면 안 지켜진다 → 게이트로 만든다.**
